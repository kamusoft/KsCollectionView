## ADDED Requirements

### Requirement: 親の状態の観測
利用者は、テンプレートの中で読む親 View の状態を「観測する値」として `KsCollectionView` に 1 つ渡せる (SHALL)。観測する値は `Hashable` であればよく、複数の状態は 1 つの値にまとめて渡す。ライブラリは観測する値が前回の更新時と異なるとき、配列が同値であっても可視セルの内容を再構成する (SHALL)。観測する値が前回と同じで配列も同値の更新では、可視セルを再構成しない (SHALL NOT)。観測する値を渡していない場合の挙動は変えない: 配列が同値でも親 View の更新が届くたびに可視セルを再構成する (SHALL、ios/ADR-0006)。観測する値の変化は差分計算と snapshot 適用を伴わない (SHALL NOT)。配列の変化と観測する値の変化が同じ更新で届いたときは差分更新の契約に従い、観測する値はその更新時の値として記録される (SHALL)。

この契約は iOS のみに存在する。Android では親の状態の観測をフレームワークが自動で行うため、対応する API を設けない (ios/ADR-0008)。

#### Scenario: 観測する値の変化で可視セルが再構成される
- **GIVEN** 親 View の状態 (例: 展開中 ID の集合) をテンプレートの中でだけ読み、その状態を観測する値として渡した `KsCollectionView` が表示中
- **WHEN** 配列を変えずにその状態だけを変える
- **THEN** 可視セルが新しい状態を反映した内容で再描画される

#### Scenario: 観測する値が同じなら可視セルを再構成しない
- **GIVEN** 観測する値を渡した `KsCollectionView` が表示中
- **WHEN** 観測する値も配列も変えずに親 View が再評価される (無関係な状態の変化)
- **THEN** 可視セルは再構成されない (テンプレートのクロージャは再実行されない)

#### Scenario: 観測する値を渡していなければ親の更新ごとに再構成する
- **GIVEN** 観測する値を渡していない `KsCollectionView` が表示中で、テンプレートが親の状態を読み、その状態は body でも読まれている
- **WHEN** 配列を変えずにその状態だけを変える
- **THEN** 従来どおり可視セルが新しい状態を反映した内容で再描画される

#### Scenario: 観測する値の変化は差分計算を伴わない
- **GIVEN** 観測する値を渡した `KsCollectionView` が表示中
- **WHEN** 配列を変えずに観測する値だけを変える
- **THEN** 挿入・削除・移動は発生せず、snapshot は適用されない (可視セルの再構成のみ)

#### Scenario: 配列の変化と観測する値の変化が同時に届く
- **GIVEN** 観測する値を渡した `KsCollectionView` が表示中
- **WHEN** 配列の要素を追加し、同時に観測する値も変える
- **THEN** 差分更新 (追加要素の挿入と内容変化の再構成) が適用され、その後に観測する値だけを元に戻す更新でも可視セルが再構成される (値が記録されている)

#### Scenario: 複数の状態をまとめて渡す
- **GIVEN** 2 つの親の状態 (例: 展開中 ID の集合と選択中 ID) を 1 つの `Hashable` な値にまとめて観測する値として渡した `KsCollectionView` が表示中
- **WHEN** どちらか一方だけを変える
- **THEN** 可視セルが新しい状態を反映した内容で再描画される
