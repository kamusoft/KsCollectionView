## ADDED Requirements

### Requirement: 行の高さ変化検証画面の親 state 経路
iOS の検証画面「行の高さ変化」の親 state 経路は、親の展開状態を観測する値として `KsCollectionView` に渡して動作する (SHALL)。body で状態を読むことで依存を張る回避策 (展開中の行数の表示) は持たない (SHALL NOT)。画面へ遷移した直後の最初のタップから行の展開・折りたたみが反映される (SHALL)。

#### Scenario: 遷移直後の最初のタップで展開される
- **GIVEN** 検証画面「行の高さ変化」を親 state 経路で開いた直後
- **WHEN** 行を 1 回タップする
- **THEN** その行が展開された内容で表示される (他の操作を挟む必要がない)

#### Scenario: 回避策の表示を持たない
- **GIVEN** 検証画面「行の高さ変化」を表示中
- **WHEN** 画面の内容を確認する
- **THEN** 展開中の行数を示す表示は存在しない
