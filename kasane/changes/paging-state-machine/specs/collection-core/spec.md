# collection-core — デルタスペック

## MODIFIED Requirements

### Requirement: 端を表示中の端への挿入
コンテンツの先頭 (ルートのヘッダーがあればその上端) を表示範囲の上端に表示しているときに配列の先頭へ項目を挿入した場合、表示範囲は先頭に留まり、挿入した項目は表示範囲の中にアニメーションで現れる (SHALL)。同じく、コンテンツの末尾 (ルートのフッターがあればその下端。ページングを付けた一覧ではページングの表示を含む) を表示範囲の下端に表示しているときに配列の末尾へ項目を挿入した場合、表示範囲は末尾に留まり、挿入した項目は表示範囲の中にアニメーションで現れる (SHALL)。どちらも両プラットフォーム・list / グリッドの両方で成り立ち、挿入した項目が表示範囲の外にひっそり足されてはならない (SHALL NOT)。グループありで最初のグループの先頭・最後のグループの末尾に挿入した場合も同じとする (SHALL)。表示範囲の外 (端を表示していない状態) での挿入の見え方は契約に含めない。

ただし、ページングを付けた一覧では、末尾に留めるのは差し替えの直前のページングの状態が終端のときだけとする (SHALL)。直前の状態が終端以外 (待機・取り直し中・追加読み込み中・失敗) なら、末尾への挿入でも表示範囲を末尾に留めず、各プラットフォームの既定の位置の保ち方にする (SHALL)。差し替えの直前の状態とは、その差し替えより前に一覧へ渡されたページングの状態をいう。先頭側の振る舞いとページングを付けない一覧の振る舞いは変わらない (SHALL)。

#### Scenario: いちばん上での先頭への挿入
- **GIVEN** list、または 2 列のグリッドを先頭までスクロールした状態 (両プラットフォーム)
- **WHEN** 配列の先頭に 1 件挿入する
- **THEN** 表示範囲は先頭のままで、挿入した項目が先頭にアニメーションで現れ、元の項目は後ろへずれる

#### Scenario: いちばん下での末尾への挿入
- **GIVEN** ページングを付けていない list、または 2 列のグリッドを末尾までスクロールした状態 (両プラットフォーム)
- **WHEN** 配列の末尾に 1 件挿入する
- **THEN** 表示範囲は末尾のままで、挿入した項目が末尾にアニメーションで現れ、元の項目は前へずれる

#### Scenario: ルートのフッターがあるときの末尾への挿入
- **GIVEN** ページングを付けていない一覧で、ルートのフッターを宣言し、フッターの下端まで表示した状態
- **WHEN** 配列の末尾に 1 件挿入する
- **THEN** 表示範囲はフッターの下端に留まり、挿入した項目がフッターの前にアニメーションで現れる

#### Scenario: 追加読み込みで届いたページは今の位置の下に現れる
- **GIVEN** ページングを付けた一覧を末尾までスクロールし、状態が追加読み込み中で次のページの読み込み中の表示が見えている (両プラットフォーム・list / グリッド)
- **WHEN** 次のページの項目を末尾に足し、同じ回に状態を待機にする
- **THEN** 表示範囲は末尾へ送られず、届いた項目は今の位置の下に現れ、利用者がスクロールしなくても次ページ要求が続けて呼ばれることはない (残りの項目の数がしきい値を超える場合)

#### Scenario: 最後のページが届くのと同時に終端になる
- **GIVEN** ページングを付けた一覧を末尾までスクロールし、状態が追加読み込み中
- **WHEN** 最後のページの項目を末尾に足し、同じ回に状態を終端にする
- **THEN** 差し替えの直前の状態は追加読み込み中なので、表示範囲は末尾へ送られず、届いた項目は今の位置の下に現れる

#### Scenario: 終端の後に末尾へ足した項目
- **GIVEN** ページングを付けた一覧で状態が終端、末尾までスクロールした状態
- **WHEN** 配列の末尾に 1 件挿入する (状態は終端のまま)
- **THEN** 表示範囲は末尾に留まり、挿入した項目が末尾にアニメーションで現れる

## ADDED Requirements

### Requirement: 取り直しの結果は先頭から表示する
ページングを付けた一覧で、差し替えの直前のページングの状態が取り直し中なら、差し替えと同時に表示範囲をコンテンツの先頭 (ルートのヘッダーがあればその上端) にする (SHALL)。途中までスクロールしていても先頭にする (SHALL)。内部の塊の件数が変わる大きな差し替えでも同じとする (SHALL)。直前の状態が取り直し中でない差し替え (状態を取り直し中にせずに配列だけを差し替えた場合) は、この Requirement の対象外で、端を表示中の端への挿入の規則と各プラットフォームの既定の位置の保ち方に従う。

#### Scenario: 途中で取り直す
- **GIVEN** ページングを付けた 500 件の一覧を途中までスクロールした状態 (両プラットフォーム・list / グリッド)
- **WHEN** 状態を取り直し中にし、次の回に 1 ページ目の 50 件に差し替えて状態を待機にする
- **THEN** 差し替えと同時に表示範囲はコンテンツの先頭になり、末尾に張り付いて次ページ要求がすぐ呼ばれることはない

#### Scenario: 大きな一覧を取り直す
- **GIVEN** ページングを付けた 10,000 件の一覧を途中までスクロールした状態
- **WHEN** 状態を取り直し中にし、次の回に 50 件に差し替えて状態を待機にする
- **THEN** 表示範囲はコンテンツの先頭になる

#### Scenario: Pull to Refresh の取り直し
- **GIVEN** ページングを付けた一覧を先頭で引っ張り、状態が取り直し中
- **WHEN** 新しい項目を先頭に含む配列に差し替えて状態を待機にする
- **THEN** 表示範囲は先頭のままで、新しい項目が見える

#### Scenario: 状態を取り直し中にしない差し替え
- **GIVEN** ページングを付けた一覧を途中までスクロールした状態で、状態は待機
- **WHEN** 状態を変えずに配列だけを差し替える
- **THEN** 表示範囲は先頭に戻されず、各プラットフォームの既定の位置の保ち方になる
