案 A: 操作を上部に固定

ナビゲーションバー直下に操作領域を固定し、その下がグリッド。操作領域は 2 行: プリフェッチの 3 択 (なし / ディスクまで / メモリまで、初期値「ディスクまで」) と、件数・列数の表示 + 「キャッシュを消去」。

セル: 正方形の KsImage (fill) + ID の文言 (「#1」)。#10〜#15 は 読み込み中の既定表示 (無地)、#12 は 失敗の既定表示 (無地 + 中央の印)。

色面は公開プレースホルダー画像の代わり。トークンは SampleTheme (accent / bg / cell / text / text2 / separator) と同値。読み込み中・失敗の無彩色は本体の定数でトークン化しない。
