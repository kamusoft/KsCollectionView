# 体感ゲート: Android「並べ替え」画面 (tasks 6.2)

並べ替えのスイッチを有効にした一覧 (全項目に長押しからのドラッグの検出が付く) を、基準機の手動フリックで確かめる記録 (design Decision 9)。iOS の対は [perf-ios-reorder.md](perf-ios-reorder.md)。

## 環境

| 項目 | 値 |
|---|---|
| 機種 / OS | Pixel 4a (基準機、Android 13 / API 33) |
| 構成 | benchmark (release と同じ最適化 + profileable、debug 鍵で署名。samples/android の `:app:assembleBenchmark`) |
| fixture | Sample「並べ替え」(全 10,000 件・100 件ずつのグループ・見出しの固定・リスト・並べ替えのスイッチはオン (既定)・10 の倍数は動かせない)。起動の Intent の追加値 `ks_start_route=demo/Reorder` |
| 駆動 | オーナーの手動フリック (自動化なし) |
| 記録 | `dumpsys gfxinfo <package> reset` から `dumpsys gfxinfo <package> framestats` まで。記録窓の実長 42 s (オーナーの準備の合図の後に reset、操作列の終了の合図の後に回収。合図の往復と操作の前後の静止を含む) |
| 熱状態 | 記録していない (gfxinfo には無い) |

## 操作条件

| 項目 | 値 |
|---|---|
| 操作列 | 初回 10 秒 → 休止 3 秒 → 再訪 5 秒 → 連続 10 秒。並べ替えのドラッグはしていない |
| 開始位置 / 到達範囲 | 先頭 (起動直後、グループ 1 の Item 1)。初回の 10 秒の間に末尾には到達していない (オーナーに確認)。それ以外の到達範囲は記録していない |
| 文字サイズ / キャッシュ状態 | 端末の文字の倍率 1.0 (`settings get system font_scale`)。アプリを削除して入れ直した直後の起動 (cold) |
| 起動引数の確認 | 起動直後にオーナーが、タイトル「並べ替え」・先頭のグループ 1 と Item 1・パネルの「並べ替え」がオンを、スクロールせずに確認 |

## オーナーの体感 (合否の主語。数値を見る前に聞き取り、2026-09-30)

- 初回 / 再訪 / 連続 / ムラ: 「問題なし」
- 見出しの固定の見え方: iOS で報告された「押し出される見出しの高さが伸びる・戻しても余白が残る」現象について、Android では「問題なし」

## 数値 (証跡。合否ではない)

取得源: `dumpsys gfxinfo framestats` の集計 (単位 ms。フレーム時間は描画 1 フレームの所要時間の分布。Macrobenchmark の指標とは別物で並べて比べない)

| 指標 | 値 |
|---|---|
| 描画フレーム数 | 1,101 (記録窓 42 s。無操作の時間を含む) |
| Janky frames | 6 (0.54 %) |
| Janky frames (legacy) | 9 (0.82 %) |
| Frame deadline missed | 6 |
| フレーム時間 P50 / P90 / P95 / P99 | 11 / 16 / 17 / 19 ms |
| GPU P50 / P90 / P95 / P99 | 5 / 6 / 8 / 10 ms |
| Missed Vsync / Slow UI thread / Slow issue draw commands / Slow bitmap uploads | 0 / 5 / 2 / 0 |
| High input latency | 276 |
| ヒストグラムの山 | 10 ms (298 枚) を中心に 9〜17 ms にほぼ収まる。20 ms を超えるのは 10 枚 (28 ms 3 枚・46 ms 2 枚・22 / 23 / 61 / 69 / 89 ms 各 1 枚) |

## 判定

- 体感の合否: **合格** (オーナー)
- 数値との一致・不一致: 期限超過 6 枚 (0.54 %)・Missed Vsync 0 で、体感と食い違わない
- 前回との比較可否: 「並べ替え」画面の記録は初めてで、比較の対象なし。「ページング」画面の記録 (paging-state-machine) とは fixture が違う (グループ・見出しの固定・並べ替えのスイッチ) ため比較不能

## 限界

- 独立試行は 1 回。対照 (計測器なし) は体感が迷いなく合格のため行っていない
- 20 ms を超える 10 枚が操作列のどの段階で出たかは、framestats の時刻と操作の時刻を突き合わせていないため分からない
- 熱状態・到達範囲 (初回の末尾未到達以外) は記録していない
- 並べ替えのドラッグ中の滑らかさ (持ち上げ・自動スクロール) はこの記録の対象外で、6.3 の目視で確かめる
