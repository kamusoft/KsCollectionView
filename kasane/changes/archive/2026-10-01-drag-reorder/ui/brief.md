# UI Brief: drag-reorder

## 画面と状態

UI に触れるのは 2 点。ライブラリ本体のドラッグ中の見え方と、Sample のデモ画面「並べ替え」(sample-parity 準拠)。挙動の正はデルタスペック (いつドラッグが始まり、どこへ置けて、何を知らせるか)、見た目の正は承認 mock とこの brief。

### ドラッグ中の見え方 (ライブラリ本体)

ライブラリはドラッグ中の見た目を独自に決めず、各プラットフォームの自然な形に寄せる (長押しで持ち上げる操作は両 OS のコレクションの標準)。

- **iOS**: UIKit のドラッグ & ドロップの標準の見え方のまま (持ち上げたセルの見た目・置く先の隙間・置いたときの動き・端での自動スクロール・受け入れないときに元の位置へ戻る動き)。ライブラリは見え方を上書きしない
- **Android**: 持ち上げた項目は指に付いて動き、ほかの項目と固定の見出しより手前に描く。ほかの項目は配置のアニメーション (android/ADR-0006 と同じ `animateItem`) で動いて場所を空ける。持ち上げ中の見た目 (浮いて見える影と少しの拡大など) は iOS の標準の見え方に近づけ、値は実装で決めて両プラットフォームを並べてオーナーの目で確かめる。受け入れないときは元の位置へアニメーションで戻る
- 端での自動スクロールの速さと反応する範囲は各 OS の自然な形 (Android は iOS の標準に近い既定)。公開の設定は持たない
- 置けない場所では、iOS は UIKit の「置けない」の見え方、Android は項目がその場所へ入らない (ほかの項目が動かない) ことで示す
- ドラッグ中は元のグループの見出しを残し、固定の見出しの下を項目が通るときの重なり順 (持ち上げた項目が手前) を実装の最初に確かめる (design の Risks)

### Sample「並べ替え」

- **ルートメニュー**: 既存のデモ画面の末尾 (「ページング」の次) に「並べ替え」を追加。両プラットフォームで同じ位置
- **一覧**: 全 10,000 件。行は「リスト」画面と同じ見た目 (タイトル「Item n」)。10 の倍数の項目はタイトルの後ろにテキスト副の色で「(移動不可)」を添える。グループの見出しは「グループ化」画面と同じ帯 (グループ名を左に太字、件数「100 件」を右にテキスト副。背景は画面の背景と同じ。上端に固定)。グループとグループの間の間隔も「グループ化」と同じ。グリッドは 2 列で「差分更新」のグリッドと同じセルの見た目 (四角い面・間隔 1)
- **操作のパネル**: 「ページング」と同じ浮いたパネル (背景が透ける面・角丸・外周の余白・左端の丸いボタンに畳める・画面の下端から上げて浮かせ、一覧の余白は変えない — handbook/cross/sample-debug-controls)。中身は「リスト / グリッド」のセグメント (左に畳む「‹」)、4 つの切り替え (並べ替え・グループ・グループをまたがせない・置いても受け入れない)、説明の一行「全 10,000 件・10 の倍数は移動不可」。4 つの切り替えの並べ方は案 A / B で異なる (承認モック)
- **帯**: 「長押し: Item N」と「並べ替えを受け入れませんでした」は、画面の上 (バーのすぐ下) の帯で出して 3 秒で消す。「ページング」の「更新できませんでした」と同じ出し方 (セル背景の面・区切り線色の枠・パネルと同じ影・テキスト主の太字)
- **画面の置き方**: 「ページング」と同じ (一覧を画面の下端まで広げる)
- **状態**: ① 通常 / ② ドラッグ中 / ③ 受け入れない (帯) / ④ 並べ替えオフで長押し (帯) / ⑤ グリッド・グループなし / ⑥ パネルを畳んだ
- **パネルの部品**: 「ページング」の画面専用の部品 (パネルの面・畳むボタン・丸いボタン・寸法・帯) を Sample の共通部品に切り出して両画面で使う (design Decision 8)。「ページング」の見た目は変えない

### 許容する差異 (sample-parity)

- OS 標準 chrome: `NavigationStack` ⇔ `Scaffold` + `TopAppBar`、セグメント・スイッチの形状
- ドラッグ中の見え方 (iOS は UIKit の標準、Android はそれに近づけた自前の見え方)。持ち上げ・隙間・戻る動きの細部はプラットフォームで違ってよいが、何がどこへ動くかは同じ
- 操作のパネルの透け方は両プラットフォームで同じ半透明の色で作り、ぼかしは使わない (「ページング」と同じ)

## 承認モック

案 B を採用 (`mock/reorder-variant-b-chips.html`、6 つの状態を並べて撮った `mock/approved.png`。2026-09-29 オーナー承認)。案 A (`mock/reorder-variant-a-switches.html`、OS 標準のスイッチを縦に並べる) に対し、パネルの背が低く、ドラッグで下端まで運ぶとき (端での自動スクロールは一覧の下端の近くで起きる) に一覧の下寄りが隠れにくい点で案 B を推奨し、承認された。

- 操作のパネル: セグメント (リスト / グリッド) と、その左の「‹」(畳む)、4 つの切り替えを 2×2 のトグルのボタン (上段「並べ替え」「グループ」、下段「グループをまたがせない」「置いても受け入れない」。オンはアクセントの面にアクセントの上の色の太字、オフはセル背景の面に区切り線色の枠)、説明の一行「全 10,000 件・10 の倍数は移動不可」(テキスト副)。面・枠・角丸・影・外周の余白・下端から上げる量は「ページング」のパネルと同じ
- 畳んだとき: 左端 (余白を取った位置) の丸いボタン「›」だけが残る
- 帯: 画面の上 (バーのすぐ下) に「並べ替えを受け入れませんでした」/「長押し: Item N」
- 一覧: 見出しの帯 (「グループ n」と「100 件」)、行「Item n」、10 の倍数は「(移動不可)」をテキスト副で添える。グリッドは 2 列・間隔 1
- ② ドラッグ中の持ち上げ・隙間の見た目は目安で、実装は各 OS の標準 (Android は iOS の標準に近づける) に従う
- 案 B のトグルのボタンの文言「グループをまたがせない」は、パネルの幅によって 2 行に折り返してよい

トークンは SampleTheme と同値 (ライトの組: accent #2F6FED / onAccent #FFFFFF / bg #F2F2F7 / cell #FFFFFF / text #111214 / text2 #6E7076 / separator #D9D9DE)。ダークの組はパネル・トグルのボタン・帯も含めて SampleTheme のダークの組の同じ名前の値を使う (cross/ADR-0007)。
