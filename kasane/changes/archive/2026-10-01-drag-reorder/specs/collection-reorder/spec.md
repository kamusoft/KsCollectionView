# collection-reorder — デルタスペック

両プラットフォーム共通の契約。語彙の対応 (Swift の `.reorder(...)` / Kotlin の `KsReorder`) は design.md Decision 1。

## ADDED Requirements

### Requirement: 並べ替えのスイッチ
一覧は並べ替えの設定 (有効 / 無効のスイッチ、置いたときの処理、任意の「動かせるか」「ここに置けるか」の判定、任意の読み上げの文言) を受け取る (SHALL)。スイッチが有効の間は、動かせる項目を長押しするとその項目のドラッグが始まる (SHALL)。スイッチが無効の間、または並べ替えを設定していない一覧では、長押ししてもドラッグは始まらない (SHALL NOT)。ドラッグ中にスイッチが無効になったら、ドラッグを取りやめて項目を元の位置に戻し、置いたときの処理を呼ばない (SHALL)。ドラッグ中に layout 値かグループの宣言が変わったときも、同じくドラッグを取りやめる (SHALL)。

#### Scenario: 有効の間は長押しでドラッグが始まる
- **GIVEN** 並べ替えのスイッチを有効にした一覧
- **WHEN** 項目を長押しする
- **THEN** その項目のドラッグが始まり、指に合わせて動かせる

#### Scenario: 無効の間はドラッグが始まらない
- **GIVEN** 並べ替えのスイッチを無効にした一覧 (並べ替えを設定していない一覧も同じ)
- **WHEN** 項目を長押しして指を動かす
- **THEN** ドラッグは始まらず、並びは変わらない

#### Scenario: ドラッグ中にスイッチが無効になる
- **GIVEN** 項目をドラッグしている
- **WHEN** スイッチが無効になる
- **THEN** ドラッグが取りやめになって項目は元の位置に戻り、置いたときの処理は呼ばれない

#### Scenario: ドラッグ中に layout が変わる
- **GIVEN** 項目をドラッグしている
- **WHEN** layout を list から 2 列のグリッドへ差し替える (グループの宣言を変えても同じ)
- **THEN** ドラッグが取りやめになって項目は元の位置に戻り、置いたときの処理は呼ばれず、一覧は新しい layout で表示される

#### Scenario: list とグリッドの両方で効く
- **GIVEN** スイッチを有効にした一覧
- **WHEN** layout を list から 2 列のグリッドへ差し替えてから項目をドラッグして置く
- **THEN** グリッドでも同じように並べ替えられ、置いたときの処理が呼ばれる

### Requirement: 置いたときの知らせ
一覧は、ドラッグした項目を置いたときに 1 回だけ、置いたときの処理に「動かした項目と行き先」を渡して呼ぶ (SHALL)。ドラッグの途中で項目が入れ替わるたびには呼ばない (SHALL NOT)。動かした項目と行き先の項目は、配列の要素そのものを渡す (SHALL)。行き先は「この項目の前」か「末尾」のどちらかで表し、置いた位置の後ろに同じグループの項目があれば「その項目の前」、置いた位置がグループの最後 (グループを宣言していなければ一覧の最後) なら「末尾」とする (SHALL)。グループを宣言している一覧では行き先のグループの値を添え、宣言していなければ添えない (SHALL)。ドラッグ中、一覧は利用者の配列を書き換えない (SHALL NOT)。元の位置に置いたとき、ドラッグが取りやめになったときは、置いたときの処理を呼ばない (SHALL NOT)。

#### Scenario: 置いたときに 1 回だけ知らせる
- **GIVEN** 項目 A, B, C, D の一覧 (グループなし) で、A をドラッグしている
- **WHEN** A を B と C を越える位置まで動かし、C と D の間で指を離す
- **THEN** 置いたときの処理は 1 回だけ呼ばれ、動かした項目は A、行き先は「D の前」で、グループの値は添えられない

#### Scenario: 最後に置いたら末尾
- **GIVEN** 項目 A, B, C の一覧 (グループなし)
- **WHEN** A をドラッグして C の後ろに置く
- **THEN** 行き先は「末尾」になる

#### Scenario: 元の位置に置いたら知らせない
- **GIVEN** 項目 B をドラッグしている
- **WHEN** B を元の位置に戻して指を離す
- **THEN** 置いたときの処理は呼ばれない

### Requirement: 並べ替えは一覧の中だけ
ドラッグした項目は、ドラッグを始めた一覧の中にだけ置ける (SHALL)。同じアプリの別の一覧やアプリの外には置けず、ほかの一覧からドラッグしてきた項目は受け付けない (SHALL NOT)。

#### Scenario: 別の一覧には置けない
- **GIVEN** 並べ替えを有効にした一覧 P と Q を同じ画面に並べている
- **WHEN** P の項目をドラッグして Q の上で指を離す
- **THEN** Q には入らず、P の項目は元の位置に戻り、P・Q どちらの置いたときの処理も呼ばれない

### Requirement: 受け入れと元に戻す
置いたときの処理は、並べ替えを受け入れたかを真偽値で返す (SHALL)。受け入れないと返したら、一覧は項目を元の並びに戻す (SHALL)。受け入れたと返したら、一覧は置いた並びのまま次の配列を待ち、置いた時点の配列と違う配列が届いたらその並びに従う (SHALL)。置いた時点の配列と同じ配列での描き直し (ほかの状態の変化による再描画) では、置いた並びのまま待つ (SHALL)。時間の経過で元に戻すことはしない (SHALL NOT)。

#### Scenario: 受け入れないと元に戻る
- **GIVEN** 置いたときの処理が受け入れないと返す一覧
- **WHEN** 項目をドラッグして別の位置に置く
- **THEN** 項目は元の位置に戻り、配列は変わらない

#### Scenario: 受け入れたら配列が届くまで置いた並びのまま
- **GIVEN** 置いたときの処理が受け入れたと返し、並べ替えた配列を少し遅れて渡す VM
- **WHEN** 項目を別の位置に置く
- **THEN** 配列が届くまでの間も項目は置いた位置に表示され、配列が届いた後もその位置のままになる

#### Scenario: 配列が変わらない描き直しでは戻らない
- **GIVEN** 置いたときの処理が受け入れたと返し、VM がまだ並べ替えた配列を渡していない
- **WHEN** 一覧が、置いた時点と同じ配列のまま、ほかの状態の変化で描き直される
- **THEN** 項目は置いた位置のままで、その後 VM が並べ替えた配列を渡しても位置は変わらない

#### Scenario: 保存の失敗で元の並びに戻す
- **GIVEN** 並べ替えを受け入れて並べ替えた配列を渡した後、保存に失敗した VM
- **WHEN** VM が並べ替える前の並びの配列を渡す
- **THEN** 項目は元の位置の並びで表示される

### Requirement: グループをまたぐ移動
グループを宣言した一覧では、項目を別のグループへ動かせる (SHALL)。置いた位置が見出し (見出しが無ければグループとグループの間) より上なら前のグループの末尾、下なら次のグループの先頭とする (SHALL)。グループの値の書き換えは利用者が行い、一覧は項目のグループの値を書き換えない (SHALL NOT)。グループの最後の 1 件をドラッグしている間も、元のグループの見出しは残す (SHALL)。受け入れた時点で、項目が 1 件も無くなったグループは見出しごと表示しない (SHALL)。項目が 1 件も無いグループは表示されないため、そこへは動かせない (SHALL NOT)。

#### Scenario: 別のグループの途中へ置く
- **GIVEN** グループ X (A, B) とグループ Y (C, D) の一覧
- **WHEN** A をドラッグして C と D の間に置く
- **THEN** 行き先は「D の前」、グループの値は Y で知らせる

#### Scenario: 見出しの上と下
- **GIVEN** グループ X (A, B) とグループ Y (C, D) の見出しを持つ一覧で、D をドラッグしている
- **WHEN** Y の見出しより上 (B の後ろ) で指を離す / Y の見出しより下 (C の前) で指を離す
- **THEN** 前者は行き先「末尾」・グループの値 X、後者は行き先「C の前」・グループの値 Y で知らせる

#### Scenario: 見出しの無いグループでも境目で分かれる
- **GIVEN** 見出しを宣言していないグループ X (A, B) と Y (C, D) の一覧
- **WHEN** D をドラッグし、X と Y の間の境目より上で指を離す
- **THEN** 行き先は「末尾」・グループの値 X で知らせる

#### Scenario: 最後の 1 件をドラッグしても見出しは残る
- **GIVEN** グループ X (A) とグループ Y (B, C) の一覧
- **WHEN** A をドラッグして Y の中へ動かしている間
- **THEN** X の見出しは表示されたままで、A を X へ戻すこともできる

#### Scenario: 受け入れると空のグループが消える
- **GIVEN** グループ X (A) とグループ Y (B, C) の一覧で、A を Y の中へ置いた
- **WHEN** 置いたときの処理が受け入れたと返す
- **THEN** X は見出しごと表示されなくなり、その後 VM が A のグループの値を Y に書き換えた配列を渡しても表示されないまま

### Requirement: 動かせるかと置けるかの判定
一覧は任意の「動かせるか」(項目ごと) と「ここに置けるか」(ドラッグ中の行き先の候補ごと) の判定を受け取る (SHALL)。「動かせるか」が偽の項目は長押ししてもドラッグが始まらない (SHALL NOT)。「ここに置けるか」には置いたときの知らせと同じ形 (動かした項目・行き先・グループの値) を渡し、偽の行き先には項目が入らない (SHALL NOT)。置けない場所の上で指を離したら、項目を元の位置に戻して置いたときの処理を呼ばない (SHALL)。判定を渡さなければ、すべての項目を動かせ、すべての位置に置ける (SHALL)。

#### Scenario: 動かせない項目
- **GIVEN** 「動かせるか」が項目 B にだけ偽を返す一覧
- **WHEN** B を長押しして指を動かす
- **THEN** ドラッグは始まらない (ほかの項目は動かせる)

#### Scenario: グループをまたがせない
- **GIVEN** 「ここに置けるか」が「行き先のグループが元のグループと同じ」ときだけ真を返す一覧
- **WHEN** グループ X の項目をドラッグしてグループ Y の中へ動かし、指を離す
- **THEN** 項目は Y の中へ入らず、指を離すと元の位置に戻り、置いたときの処理は呼ばれない

### Requirement: 端での自動スクロール
ドラッグ中に指が一覧の見えている範囲の上端か下端の近くにある間、一覧はその向きにスクロールを続ける (SHALL)。スクロールで見えた位置に項目を置ける (SHALL)。

#### Scenario: 画面の外の位置へ運ぶ
- **GIVEN** 1 画面に収まらない一覧で、先頭付近の項目をドラッグしている
- **WHEN** 指を一覧の下端の近くに置いたままにする
- **THEN** 一覧が下へスクロールし続け、指を上へ戻すと止まり、スクロールした先で置ける

### Requirement: 読み上げの移動操作
スイッチが有効で、読み上げの文言 (「前へ移動」「後ろへ移動」に当たる 2 つ) を渡した一覧では、動かせる項目に読み上げ用の 2 つの操作を出す (SHALL)。文言を渡さなければ操作を出さない (SHALL NOT)。スイッチが無効の間と、動かせない項目には出さない (SHALL NOT)。「前へ移動」は並びで 1 つ前へ、グループの先頭の項目なら前のグループの末尾へ動かす (SHALL)。「後ろへ移動」は 1 つ後ろへ、グループの最後の項目なら次のグループの先頭へ動かす (SHALL)。一覧の先頭の項目に「前へ移動」、最後の項目に「後ろへ移動」は出さず、「ここに置けるか」が偽の行き先になる操作も出さない (SHALL NOT)。操作で動かしたときも、置いたときの処理・受け入れ・元に戻す扱いはドラッグと同じ (SHALL)。

#### Scenario: 操作で 1 つ後ろへ動かす
- **GIVEN** 文言を渡し、スイッチを有効にした項目 A, B, C の一覧 (グループなし)
- **WHEN** 読み上げの操作で A の「後ろへ移動」を実行する
- **THEN** 置いたときの処理が 1 回呼ばれ、動かした項目は A、行き先は「C の前」になる

#### Scenario: グループの境目を越える操作
- **GIVEN** グループ X (A, B) とグループ Y (C, D) の一覧
- **WHEN** C の「前へ移動」を実行する
- **THEN** 行き先は「末尾」・グループの値 X で知らせる

#### Scenario: 操作を出さない場合
- **GIVEN** 文言を渡した一覧
- **WHEN** スイッチを無効にする / 動かせない項目 / 一覧の先頭の項目の操作を調べる
- **THEN** スイッチが無効ならどの項目にも操作は無く、動かせない項目にも無く、先頭の項目には「前へ移動」が無い

### Requirement: ドラッグ中に届いた配列
ドラッグ中 (ドラッグが始まってから、置いて受け入れの結果が出るまで) に届いた配列は、表示に当てずに最新の 1 つを控える (SHALL)。受け入れたら控えた配列を捨て、受け入れた後に届く配列に従う (SHALL)。受け入れなかったとき・ドラッグを取りやめたとき・元の位置に置いたときは、項目を元の位置に戻してから控えた最新の配列を当て、最新の配列の並びで表示する (SHALL)。

#### Scenario: ドラッグ中の配列は指を離すまで当たらない
- **GIVEN** 項目をドラッグしている
- **WHEN** VM がほかの項目の中身を変えた配列を渡す
- **THEN** 指を離すまで表示は変わらない

#### Scenario: 受け入れたら控えた配列を捨てる
- **GIVEN** ドラッグ中に、並べ替えを含まない配列が届いて控えられている
- **WHEN** 項目を置き、受け入れたと返し、VM が並べ替えを含む配列を渡す
- **THEN** 控えた配列の並びに一度戻ることはなく、置いた並びのまま VM の配列に従う

#### Scenario: 受け入れなければ最新の配列へ戻る
- **GIVEN** ドラッグ中に、末尾に項目を足した配列が届いて控えられている
- **WHEN** 項目を置き、受け入れないと返す
- **THEN** 項目は元の位置に戻り、足された項目も表示される

#### Scenario: ドラッグ中の項目が消えた配列を控えて受け入れない
- **GIVEN** 項目 B をドラッグしている間に、B を取り除いた配列が届いて控えられている
- **WHEN** B を置き、受け入れないと返す
- **THEN** B は元の位置に戻ってから表示されなくなる

### Requirement: ドラッグ中のページングとスクロール命令
ページングを付けた一覧では、ドラッグ中は次のページを頼まない (SHALL NOT)。ドラッグが終わったら (置いた・取りやめた後に) 次のページを頼むかを判定し直す (SHALL)。ドラッグ中に受けたスクロール命令は、ドラッグが終わって配列を表示に当てた後に、受けた順に実行する (SHALL)。

#### Scenario: ドラッグ中は次のページを頼まない
- **GIVEN** ページングを付け、状態が待機の一覧で、項目をドラッグしている
- **WHEN** 端での自動スクロールで末尾の近くまで運ぶ
- **THEN** ドラッグ中は次ページ要求の処理が呼ばれず、指を離した後に末尾の近くなら呼ばれる

#### Scenario: ドラッグ中のスクロール命令は後で実行する
- **GIVEN** 項目をドラッグしている
- **WHEN** VM が先頭へのスクロール命令を出す
- **THEN** ドラッグ中は一覧が命令でスクロールせず、指を離して配列を当てた後に先頭へスクロールする
