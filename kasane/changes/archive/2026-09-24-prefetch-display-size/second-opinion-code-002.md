## 指摘事項

### 🟠 Major — iOS でメモリのみ消去した後、表示中の画像が読み込み中に戻り得る

**該当箇所:** `ios/Sources/KsCollectionView/KsImage.swift:122`、`ios/Sources/KsCollectionView/KsImageCache.swift:31`

**問題点:** `clear(.memory)` はキャッシュと引き当て索引を消します。その後、画像ソースや枠が変わっていなくても親ビューの状態変化などで `KsImage` が再評価されると、`prepare` は画像を引き当てられず、表示中の画像が `LazyImage` と読み込み中の表示へ切り替わります。「メモリのみ消去は表示中の画像を置き換えない」という仕様に反します。既存テストは消去後の新たな取得を確認していますが、表示中のビューの再評価は確認していません。

**推奨修正:** 表示中に引き当てた画像を、そのビューのソース・枠・削除世代が変わらない間は保持してください。`clear(.memory)` 後に親ビューを再評価しても読み込み中の表示へ戻らない回帰テストを追加してください。

前回採用された「共有キーの署名 URL 差し替え」は、両プラットフォームで旧要求を停止して新 URL へ切り替える実装とテストを確認しました。前回の降格指摘は再掲していません。指定されたテスト結果を前提とした静的レビューで、ビルド・テストは実行していません。

**判定: CHANGES_REQUESTED**
