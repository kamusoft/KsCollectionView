# 体感ゲート: Android「ページング」画面 (tasks 7.3 / 7.2)

## 環境
- 機種: Pixel 4a (基準機、Android 13 / API 33)
- ビルド構成: benchmark (release と同じ最適化 + profileable、debug 鍵で署名。samples/android の `:app:assembleBenchmark`)
- 実装: 次のページの読み込み中の表示を見えている範囲の下端 (下端のシステムバーとの重なり + 8dp) に下地なしで止めて重ねる形、Sample のパネルを上げて一覧の下の余白をシステムバーの分だけにした形 (deviation.md)
- fixture: Sample「ページング」(全 10,000 件・1 ページ 50 件)、リスト表示。起動の Intent の追加値 `ks_start_route=demo/Paging`、`ks_paging_delay_ms=200`
- 駆動: 手動 (オーナー)
- 記録手段: `dumpsys gfxinfo <package> reset` から `dumpsys gfxinfo <package> framestats` まで。記録窓の実長: 66.3 s (合図の往復と操作の前後の静止を含む)
- 熱状態: 記録していない (gfxinfo には無い)

## 操作条件
- 開始位置・方向・段階: 先頭 (起動直後、Item 1) から、初回 下向き 10 秒 → 休止 3 秒 → 再訪 上向き 5 秒 → 連続 下向き 10 秒
- キャッシュ状態: アプリを削除して入れ直した直後の起動 (cold)
- 文字サイズ: 端末の文字の倍率 1.0 (`settings get system font_scale`、記録の後に確認)
- 到達範囲: 記録していない
- 起動引数の確認: 起動直後の最初の読み込み中の表示がすぐ消えて Item 1 から並んだことをオーナーが確認 (スクロールせずに確認)

## オーナーの体感 (数値を見る前に聞き取り、2026-09-29)
- 起動時・初回・再訪・連続・7.2 (下端のくるくるの出入りと項目の跳ね): 「1〜5 問題なし」
- 区切り線 (参考): 「iOS ほどではないけど行が細くなる現象あり」(別 change `list-separator-blur-on-fast-scroll` で扱う。判定に入れない)

## 数値
取得源: `dumpsys gfxinfo framestats` の集計 (単位 ms、フレーム時間は描画 1 フレームの所要時間の分布。Macrobenchmark の指標とは別物で並べて比べない)

| 指標 | 値 |
|---|---|
| 描画フレーム数 | 1,814 (記録窓 66.3 s。無操作の時間を含む) |
| Janky frames | 12 (0.66 %) |
| Janky frames (legacy) | 359 (19.79 %) |
| Frame deadline missed | 12 |
| フレーム時間 P50 / P90 / P95 / P99 | 16 / 29 / 31 / 34 ms |
| Missed Vsync / Slow UI thread / Slow issue draw commands / Slow bitmap uploads | 0 / 11 / 2 / 0 |
| High input latency | 2,100 |
| ヒストグラムの山 | 10〜12 ms (約 545 枚)、16〜17 ms (約 606 枚)、28〜32 ms (約 276 枚)。最長は 57 ms と 61 ms が各 1 枚 |

## 判定
- **合格** (7.3 の Android)。オーナーの体感は起動時・初回・再訪・連続とも問題なし。期限超過は 12 枚 (0.66 %)・Missed Vsync 0 で、体感と食い違わない
- 7.2 (下端の読み込み中の表示の出入りと項目の跳ね): オーナーの目視で問題なし
- 前回との比較: 「ページング」画面の Android の記録は初めてで、比較の対象なし
- 区切り線: 判定に入れない (別 change)

## 限界
- 記録窓は合図の往復と操作前後の静止を含むため、フレーム数を操作の区間の密度として読めない。区間ごとの値は取っていない (Perfetto のトレースは採っていない)
- 記録回数は 1 回。対照 (計測器なし) は行っていない (体感が迷いなく合格で、gfxinfo は計測の負荷が小さいため)
- 熱状態は記録していない
- 到達範囲 (各段階でどの項目まで進んだか) は記録していない
- この記録の後、差し替えた次のページの読み込み中の表示の範囲から始めたドラッグの扱い (一覧のスクロールに渡す・インジケータとオーバースクロールを一覧と共有する) を直した (review-004 / review-005)。Sample は表示を差し替えておらず、差し替えていない一覧ではオーバースクロールの効果を既定と同じものを明示的に渡す形になっただけで、計測した経路は変わらないため、取り直していない
