# Delta Spec: image-loading (library-default-colors-dark-mode)

両プラットフォーム共通。既存の「KsImage の表示状態」(読み込み中・失敗の表示は差し替えられ、未指定なら既定の表示を出す) は変えず、既定の表示の色の扱いを足す。既定の表示の形 (読み込み中は無地、失敗は下地と印) は変えない。

## ADDED Requirements

### Requirement: KsImage の既定の表示の色
読み込み中・失敗の表示を差し替えていない `KsImage` が出す既定の表示 (読み込み中の無地、失敗の下地、失敗の印) の色は、ライト用とダーク用の 2 組の値を持ち、描くときの表示モードの側の値で描く (SHALL)。値はライト・ダークとも両プラットフォームで同じとする (SHALL)。表示モードの決め方は区切り線の既定の色と同じとする: iOS では `KsImage` が置かれた場所の外観 (アプリが上書きした外観を含む)、Android では `KsImage` が置かれた画面の構成の夜間モード (通常は端末の表示モードに追随し、アプリが画面の構成を上書きしたときはその値。Material のテーマの配色は判定に使わない) (SHALL)。表示中に表示モードが切り替わると、出ている既定の表示は切り替わった側の色で描かれる (SHALL)。表示モードの切り替えだけでは、進行中の取得を取り消さず、新しい取得も始めない (SHALL NOT)。既定の読み込み中の表示は、出る経路 (読み込みを始めてから出る場合と、先読みの完了を待つ間に出る場合) によらず同じ色で描く (SHALL)。一覧の外に置いた `KsImage` も同じ扱いとする (SHALL)。利用者が差し替えた読み込み中・失敗の表示に、ライブラリは色を当てない (SHALL NOT)。

**Side Effects**: なし

#### Scenario: ライトの読み込み中
- **GIVEN** 表示を差し替えていない、メモリキャッシュに項目が無いリモート URL の `KsImage`。表示モードはライト
- **WHEN** 表示する
- **THEN** 取得が終わるまで、既定の読み込み中の表示がライト用の色で描かれる

#### Scenario: ダークの読み込み中
- **GIVEN** 表示を差し替えていない、メモリキャッシュに項目が無いリモート URL の `KsImage`。表示モードはダーク
- **WHEN** 表示する
- **THEN** 取得が終わるまで、既定の読み込み中の表示がダーク用の色で描かれる

#### Scenario: ライトとダークの失敗
- **GIVEN** 表示を差し替えていない、取得できないソースの `KsImage`
- **WHEN** ライトで表示する / ダークで表示する
- **THEN** 既定の失敗の表示の下地と印が、それぞれの表示モードの側の色で描かれる

#### Scenario: 表示中に表示モードが切り替わる
- **GIVEN** 既定の読み込み中の表示、または既定の失敗の表示をライトで出している `KsImage`
- **WHEN** 画面を作り直さずに表示モードをダークに切り替え、その後ライトに戻す
- **THEN** 出ている既定の表示がダーク用の色になり、戻すとライト用の色に戻る。表示の状態 (読み込み中・失敗) は切り替えの前後で変わらない

#### Scenario: 取得の途中で表示モードが切り替わる
- **GIVEN** 既定の読み込み中の表示を出して取得が進行中の `KsImage` (読み込みを始めてから出た場合と、先読みの完了を待つ間に出た場合のそれぞれ)
- **WHEN** 画面を作り直さずに表示モードを切り替える
- **THEN** 切り替えで取得は取り消されず、新しい取得も始まらない。取得が終わると、その結果の画像が表示される

#### Scenario: 先読みの完了を待つ間の読み込み中
- **GIVEN** 表示を差し替えていない `KsImage` を、同じ画像の先読みが取得中のうちに一覧が組み立てた。表示モードはダーク
- **WHEN** その `KsImage` が画面に出る
- **THEN** 画面に出た最初の描画から、既定の読み込み中の表示がダーク用の色で描かれる

#### Scenario: 上書きした表示モードで決まる
- **GIVEN** 端末の表示モードはライトで、アプリが `KsImage` を置いた画面の外観 (iOS) または画面の構成の夜間モード (Android) をダークに上書きしている
- **WHEN** 表示を差し替えていない `KsImage` が読み込み中になる
- **THEN** 既定の読み込み中の表示がダーク用の色で描かれる

#### Scenario: 差し替えた表示は変わらない
- **GIVEN** 読み込み中と失敗の表示を利用者の表示に差し替えた `KsImage`
- **WHEN** ライトで表示する / ダークで表示する
- **THEN** どちらでも利用者の表示がそのまま出て、ライブラリの既定の色は描かれない

#### Scenario: 一覧の外に置いた KsImage
- **GIVEN** 一覧の外に置いた、表示を差し替えていない `KsImage`。表示モードはダーク
- **WHEN** 読み込み中および失敗の状態になる
- **THEN** 既定の表示がダーク用の色で描かれる

#### Scenario: 両プラットフォームで同じ値
- **GIVEN** 両プラットフォームのライブラリ
- **WHEN** 読み込み中・失敗の下地・失敗の印の、ライト用とダーク用の値を比べる
- **THEN** どの値も両プラットフォームで同じで、承認 mock の色の表の値と一致する
