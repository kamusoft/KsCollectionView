# Delta Spec: samples (library-default-colors-dark-mode)

両プラットフォームの Sample。デモ画面「リスト」がタップしたときの色に渡す値をそろえる。画面の構造・文言・操作と、区切り線の選択 (既定 / アクセント / 非表示) は変えない。

## ADDED Requirements

### Requirement: デモ画面「リスト」のタップしたときの色
両プラットフォームのデモ画面「リスト」は、タップしたときの色の設定に、Sample 共通の配色の同じ色 (アクセント) へ同じ不透明度を掛けた値を渡す (SHALL)。プラットフォームごとに違う値を渡して見え方を合わせることはしない (SHALL NOT)。

**Side Effects**: なし

#### Scenario: 両プラットフォームで同じ値
- **GIVEN** 両プラットフォームの「リスト」
- **WHEN** タップしたときの色の設定に渡している値を比べる
- **THEN** 同じ名前の色に同じ不透明度を掛けた値で、両プラットフォームで一致する

#### Scenario: 押している間の見え方
- **GIVEN** 「リスト」をライト / ダークのそれぞれで開いている
- **WHEN** 行を押し続ける
- **THEN** 両プラットフォームとも、行の中身が読めるままアクセントの色みのフィードバックが出る。濃さは、iOS は渡した値どおり、Android は標準の波紋の濃さになる
