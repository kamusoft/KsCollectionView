タップしたときの色 (Sample「リスト」に渡す値)

ライブラリの挙動は変えない。Sample は両プラットフォームに同じ値を渡す。iOS は渡した色をそのまま塗り、Android は色みだけを使って標準の濃さ (約 8%。エミュレータの実測) で出す。
渡す値は「アクセント色の 10%」(2026-10-06 オーナー決定。両プラットフォームの見え方がいちばん近くなる)。比較のために、変更前の iOS の値「アクセント色の 15%」も並べた。Android はどちらを渡しても同じ見え方になる。
