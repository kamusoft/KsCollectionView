# iOS: 外観の反映とダーク / ライトの確認 (tasks 5.2・5.3 の iOS 側)

- 環境: iOS Simulator (iPhone 17 Pro / iOS 26.5、この確認専用に作った個体)、Xcode 26.5、Debug 構成
- 撮影: シミュレータ + デモデータのみ。ステータスバーは時刻 9:41・電波・電池を固定表示にし、個人要素が写っていないことを保存後に画像を開いて確かめた。画像グリッドの写真はデモ用の公開画像
- 端末の表示モードは `simctl ui appearance`、保存した外観は起動引数 `--reset-appearance` または Sample の保存先 (`UserDefaults` のキー `appearance`) で用意し、画面の操作はシミュレータへのタップで行った
- 画像のうち `ios-dark-*` と `ios-root-system-follows-device.png` は、複数の画面を 1 枚に並べた一覧 (1 枠 = 1 画面、点単位に縮小)

## 5.3 ダークで崩れない

「ダーク」を保存し、端末はライトのまま確認した。判定は `ui/brief.md` の視認性の基準。OS の標準部品とライブラリの既定の色 (区切り線「既定」・画像の読み込み中の色・スクロールインジケータ) は 5.4 の対象のため、ここでは読めるかどうかだけを見た。

配色定義のダークの組のコントラスト比 (計算): 文字 / 下地 15.52、文字 / 行 13.30、補助の文字 / 下地 6.56、補助の文字 / 行 5.62、アクセント / 下地 5.82、アクセント / 行 4.99、アクセントの上の色 / アクセント 5.82、区切り / 行 1.34。いずれも基準 (文字の組 4.5 以上、区切り / 行 1.3 以上) を満たす。

| 画面 | 行った操作 | 結果 | 画像 |
|---|---|---|---|
| ルートメニュー | 外観の 3 項目をそれぞれ選ぶ | 文字・選択の印 (アクセント)・見出し (補助の文字) が読める。選んだ項目にだけ印が付く | `ios-root-dark-after-select.png`、`ios-root-system-follows-device.png` |
| リスト | 区切り線「なし」「既定」「アクセント」を順に選ぶ | 読める。「既定」はライブラリ既定の明るい線 (Non-Goal)、「アクセント」は明るめの青の線 | `ios-dark-screens-1.png` (既定)、`ios-dark-operations-1.png` (アクセント / なし) |
| グリッド (固定列) | レイアウト「list」「grid」 | 読める。「レイアウト」の文字は文字の色 | `ios-dark-screens-1.png` (grid)、`ios-dark-operations-1.png` (list) |
| グリッド (adaptive) / 向きで列数変更 / テンプレート切り替え | 操作部品なし (表示のみ) | 読める。テンプレートの Notice はアクセントの色 | `ios-dark-screens-1.png` |

## 5.3 ライトは変わらない

変更前のビルド (作業ツリーの変更を入れる前に同じシミュレータでビルドしたもの) と変更後のビルドで、同じ 14 画面 (ルートメニュー・デモ画面 12・検証画面) を端末ライト・外観「ライト」相当で撮り、画素ごとに差を取った。

| 画面 | 結果 |
|---|---|
| ルートメニュー | 先頭に「外観」の項目群が増えた分だけ異なる (意図した変更)。既存の項目の行の色・文字の色は同じ |
| グリッド (adaptive)・向きで列数変更・テンプレート切り替え・ルートヘッダー/フッター・スクロール制御・大量件数・画像グリッド・グループ化・差分更新 | 全画素一致 |
| リスト・グリッド (固定列)・スペーシングと余白・検証: 行の高さ変化 | 差は色を指定していなかった文字 (「区切り線」「レイアウト」「スペーシング」「余白」「行の高さ変化検証」) の画素だけで、各成分の差は最大 20 / 255。OS の既定の文字色 (黒 #000000) から配色定義の文字の色 (#111214) に載せ替えたため |

最後の行は、色を指定していない文字を配色定義に載せる作業による差で、ライトの組の値そのものは変えていない。
