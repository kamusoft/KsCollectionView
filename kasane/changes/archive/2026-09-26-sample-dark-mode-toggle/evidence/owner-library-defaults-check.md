# 5.4 ライブラリの既定の色のオーナー目視 (2026-09-26)

- 端末: iOS シミュレータ「ksc-sample-dark-mode」(iOS 26.5) / Android エミュレータ「ksc-sample-dark-check」(android-35、この確認専用に作成、port 5620)
- 手順: ルートメニューの「外観」でライト / ダークを切り替え、「リスト」(区切り線「既定」・タップの反応)・「画像グリッド」(読み込み中の色)・「大量件数」(スクロールインジケータ)・「グループ化」を見る

## オーナーの所見

- 問題あり: Android の「画像グリッド」の読み込み中の色が、ダークでも明るいまま (ライブラリの既定の色。`library-default-colors-dark-mode` に記録)
- 検証のしにくさ: 「グループ化」は「グループ 1」が長すぎて、グループの境目や見出しの切り替わりを確かめにくい (Sample のデモデータの構成。扱いはオーナー判断)
- 問題なし: 上記以外 (「リスト」の区切り線「既定」がダークで明るい線のまま残る点を含む、タップの反応、「大量件数」のスクロールインジケータ、「グループ化」の見え方) はすべて問題なし
- 「グループ化」の検証のしにくさは、オーナー判断で見送り (起票しない。2026-09-26)
