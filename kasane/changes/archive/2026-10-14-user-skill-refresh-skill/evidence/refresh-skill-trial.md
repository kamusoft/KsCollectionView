### 道具の出力の確かめ (修正サイクル 1 回目、2026-10-14)

リポジトリの外に、本リポジトリの clone を使い捨てで作り、remote を外して行った。終わった後に `trash` で消した。

1. 概念の文書の置き場に、試験用の文書 A・B を足し、記録の `sources` に、どちらも `excluded` (掛からない) として足して commit した。`record` を流して記録の commit を書き換え、commit した。`status` は「変わった源泉は無い」と出た
2. A を消し、B を改名して commit した。`status` (終了コード 0) は、B を「名前の変わった源泉」に (見直す 1 枚: `Skill に掛からない (理由: …)`)、A を「無くなった源泉」に (掛かっていた 1 枚: `Skill に掛からない (理由: …)`) 出した
3. `sources` を直さずに `record` を流すと、終了コード 0 で、記録の commit の ID だけが書き換わった。commit した後の `status` は、A と B (改名の前のパス) を「無くなった源泉」に、B の今のパスを「対応の決まっていない源泉」に出した。消した源泉はそのまま出続け、改名した源泉は形を変えて出続けた
4. 記録の `sources` から A の項目を消し、B のパスを今の名前に直して、commit しないまま `status` を流すと、「変わった源泉は無い」と出た。続けて `record` を流すと、記録のファイルに commit していない変更があるのに、終了コード 0 で書き換えた (記録のファイルは、`record` を止める対象のパスに入っていない)。記録の対応表の直しを先に commit しないと、記録の commit に混ざる
