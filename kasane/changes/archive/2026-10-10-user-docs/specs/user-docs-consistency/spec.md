## ADDED Requirements

### Requirement: README の最小コード例の検査

README の最小コード例の検査は、ルートの README の 2 枚の最小コード例が、利用者役の画面のファイルの全体と一致することを確かめなければならない (SHALL)。一致しないものが 1 つでもあれば、どのファイルのどの例が違うかを出して、失敗で終わる。

検査は、何も比べずに成功で終わってはならない。最小コード例の節・コードブロック・利用者役のファイルのどれかが見つからないときは、失敗で終わる。

**Requires**:
- 渡したリポジトリのルートが、実在するディレクトリであること

**Side Effects**: なし

#### Scenario: 一致していれば成功する
- **GIVEN** README の 2 枚の最小コード例が、利用者役の画面のファイルと同じ内容である
- **WHEN** 検査を流す
- **THEN** 成功で終わる

#### Scenario: README の例だけを変えると失敗する
- **GIVEN** README の片方の、片方のプラットフォームの例を 1 文字変えた
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、どの README のどのプラットフォームの例が違うかが出る

#### Scenario: 利用者役のファイルだけを変えると失敗する
- **GIVEN** 利用者役の画面のファイルを変え、README を変えていない
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 日本語版の README も確かめる
- **GIVEN** 英語版の例は一致し、日本語版の例だけが違う
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 節が見つからないと失敗する
- **GIVEN** README から、最小コード例の節の見出しが無くなった
- **WHEN** 検査を流す
- **THEN** 失敗で終わる (何も比べずに成功しない)

#### Scenario: 無いルートでは始めない
- **GIVEN** 実在しないディレクトリを、リポジトリのルートとして渡した
- **WHEN** 検査を流す
- **THEN** 引数の誤りで終わり、何も比べない

### Requirement: インストール例の検査

インストール例の検査は、ルートの README の 2 枚と、各 `SKILL.md` のインストール例について、次のすべてを確かめなければならない (SHALL)。1 つでも満たさなければ、どのファイルの何が違うかを出して、失敗で終わる。

- 例の値 (Package URL・package の名前・product の名前・Maven の座標) が、利用者役が公開済みの配布物を取るときに使う値と同じである
- 版の位置が `{version}` で、例の中に具体の版が無い
- 最新の版の確かめ先の URL が、同じファイルにある
- README は SwiftPM と Gradle の両方の例を、iOS の `SKILL.md` は SwiftPM の例を、Android の `SKILL.md` は Gradle の例を持つ
- 英語版と日本語版で、例の種類と数が同じである

対象のファイルが無いとき、または対象のファイルに例が 1 つも無いときは、失敗で終わる。

**Requires**:
- 渡したリポジトリのルートが、実在するディレクトリであること

**Side Effects**: なし

#### Scenario: 決めた形なら成功する
- **GIVEN** 6 つのファイルのインストール例が、利用者役と同じ値で、版の位置が `{version}` で、最新の版の確かめ先を持つ
- **WHEN** 検査を流す
- **THEN** 成功で終わる

#### Scenario: 具体の版が書かれていると失敗する
- **GIVEN** どれか 1 つのファイルの例の、版の位置に具体の版を書いた
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、そのファイルが出る

#### Scenario: 値が利用者役と違うと失敗する
- **GIVEN** README の例の Package URL が、利用者役の使う URL と違う
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 最新の版の確かめ先が無いと失敗する
- **GIVEN** どれか 1 つのファイルから、最新の版の確かめ先の URL を消した
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、そのファイルが出る

#### Scenario: 例が無いファイルがあると失敗する
- **GIVEN** iOS の `SKILL.md` から、SwiftPM の例を消した
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 英語版と日本語版で例の数が違うと失敗する
- **GIVEN** 日本語版の README から、Gradle の例だけを消した
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 無いルートでは始めない
- **GIVEN** 実在しないディレクトリを、リポジトリのルートとして渡した
- **WHEN** 検査を流す
- **THEN** 引数の誤りで終わり、何も確かめない

### Requirement: Skill 自身の整合の検査

Skill 自身の整合の検査は、`skills/{en,ja}/` の下のすべての Skill について、次のすべてを確かめなければならない (SHALL)。1 つでも満たさなければ、どのファイルの何が違うかを出して、失敗で終わる。

- 英語版と日本語版で、Skill の集合・ファイルの集合・見出しの深さの並び・コードブロックの中身と順番が同じである
- `SKILL.md` の frontmatter が、決めた 5 項目だけを持ち、`name` がディレクトリの名前と同じで、`metadata.language` が置き場の言語と合う
- 相対のリンクの先が、その Skill のディレクトリの中に実在する
- URL が、許可した一覧にあるもの、または見本の URL の前置きで始まるものだけである
- 決めた内部の言葉が、本文にもコードブロックにも現れない

`skills/` が無いとき、または Skill が 1 つも無いときは、失敗で終わる。

**Requires**:
- 渡したリポジトリのルートが、実在するディレクトリであること

**Side Effects**: なし

#### Scenario: 整合していれば成功する
- **GIVEN** 上のすべてを満たす `skills/`
- **WHEN** 検査を流す
- **THEN** 成功で終わる

#### Scenario: 片方の言語だけ見出しを変えると失敗する
- **GIVEN** 日本語版の 1 枚に見出しを 1 つ足し、英語版を変えていない
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、その 1 枚が出る

#### Scenario: 片方の言語だけコードを変えると失敗する
- **GIVEN** 英語版の 1 枚のコードブロックを 1 文字変え、日本語版を変えていない
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 片方の言語にだけファイルがあると失敗する
- **GIVEN** 英語版にだけ、`references/` のファイルを 1 枚足した
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: frontmatter に決めていない項目があると失敗する
- **GIVEN** `SKILL.md` の frontmatter に、決めた 5 項目のほかの項目を足した
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: name がディレクトリの名前と違うと失敗する
- **GIVEN** `SKILL.md` の `name` を、ディレクトリの名前と違う値にした
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: Skill の外のファイルへのリンクがあると失敗する
- **GIVEN** `references/` の 1 枚に、Skill のディレクトリの外のファイルへの相対のリンクを足した
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、そのリンクが出る

#### Scenario: リンクの先が無いと失敗する
- **GIVEN** `SKILL.md` に、`references/` の実在しないファイルへのリンクがある
- **WHEN** 検査を流す
- **THEN** 失敗で終わる

#### Scenario: 許可していない URL があると失敗する
- **GIVEN** `references/` の 1 枚に、本リポジトリの中の文書への URL を足した
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、その URL が出る

#### Scenario: 許可した URL と見本の URL は通る
- **GIVEN** Package URL を書いたインストール例と、見本の URL の前置きで始まる画像の URL を書いたコード例
- **WHEN** 検査を流す
- **THEN** この 2 つは違反にならない

#### Scenario: 内部の言葉があると失敗する
- **GIVEN** `references/` の 1 枚に、ADR の番号を書いた
- **WHEN** 検査を流す
- **THEN** 失敗で終わり、その言葉と場所が出る

#### Scenario: skills が無いと失敗する
- **GIVEN** `skills/` が無い、または Skill のディレクトリが 1 つも無い
- **WHEN** 検査を流す
- **THEN** 失敗で終わる (何も確かめずに成功しない)

#### Scenario: 無いルートでは始めない
- **GIVEN** 実在しないディレクトリを、リポジトリのルートとして渡した
- **WHEN** 検査を流す
- **THEN** 引数の誤りで終わり、何も確かめない

### Requirement: 検査は検証 CI のスクリプトのテストで毎回流れる

上の 3 つの検査は、検証 CI の lint のジョブが流すスクリプトのテストの中で、今のリポジトリの実物に対して毎回流れなければならない (SHALL)。lint のジョブの step と、検証 CI の検査の名前は増やさない。

検証 CI は、Skill が源泉からずれていることと、公開の宣言の名前が Skill から漏れていることを検査してはならない (SHALL NOT)。

**Side Effects**: なし

#### Scenario: スクリプトのテストが実物を確かめる
- **GIVEN** 制作が終わったリポジトリ
- **WHEN** スクリプトのテストの入口を流す
- **THEN** 3 つの検査が今のリポジトリの実物に対して実行され、成功する

#### Scenario: 実物が崩れると、スクリプトのテストが失敗する
- **GIVEN** `skills/` の日本語版の 1 枚にだけ、見出しを 1 つ足した作業ツリー
- **WHEN** スクリプトのテストの入口を流す
- **THEN** 失敗で終わる

#### Scenario: lint の step が増えていない
- **GIVEN** 本変更の後の検証 CI の入口の定義
- **WHEN** lint のジョブの step の一覧を、変更の前と比べる
- **THEN** 同じである

#### Scenario: 源泉だけを変えても、検証 CI は落ちない
- **GIVEN** 源泉の概念の文書だけを変え、`skills/` を変えていない作業ツリー
- **WHEN** スクリプトのテストの入口を流す
- **THEN** 成功で終わる

#### Scenario: 公開の宣言だけを足しても、検証 CI は落ちない
- **GIVEN** 本体に公開の宣言を 1 つ足し、`skills/` を変えていない作業ツリー
- **WHEN** スクリプトのテストの入口を流す
- **THEN** 成功で終わる
