# Delta Spec: collection-paging (paging-indicator-color)

## ADDED Requirements

### Requirement: 読み込み中の表示の色
一覧は、ライブラリが出す読み込み中の表示の色を指定する設定を 1 つ持つ (SHALL)。色を指定すると、差し替えていない「次のページの読み込み中」、差し替えていない「最初の読み込み中」、Pull to Refresh のインジケータの 3 つが、指定した色で描かれる (SHALL)。設定は一覧そのものに付け、ページングを付けない一覧でも Pull to Refresh のインジケータに効く (SHALL)。利用者が差し替えた表示には、この設定の色を効かせない (SHALL)。表示中に指定した色を変えると、出ている表示は新しい色に変わる (SHALL)。ただし iOS では、並べ替えのドラッグ中に届いた色の変化は、ドラッグ中に届くほかの設定の変化と同じく、ドラッグが終わってから反映する (SHALL)。Android の Pull to Refresh のインジケータでは、指定した色は矢印に効き、下地の色は変えない (SHALL)。

**Side Effects**: なし

#### Scenario: 次のページの読み込み中に効く
- **GIVEN** 色を指定し、表示を差し替えていない、項目が 1 件以上の一覧
- **WHEN** 状態を追加読み込み中にする
- **THEN** 次のページの読み込み中の表示が、指定した色で描かれる

#### Scenario: 最初の読み込み中に効く
- **GIVEN** 色を指定し、表示を差し替えていない、項目が 0 件の一覧
- **WHEN** 状態が追加読み込み中、または取り直し中になる
- **THEN** 最初の読み込み中の表示が、指定した色で描かれる

#### Scenario: Pull to Refresh のインジケータに効く
- **GIVEN** 色を指定し、取り直しの処理を渡した、ページングを付けた一覧
- **WHEN** 先頭で引っ張って取り直しを始める
- **THEN** インジケータが、指定した色で描かれる

#### Scenario: ページングを付けない一覧でも効く
- **GIVEN** 色を指定し、取り直しの処理を渡し、ページングを付けていない一覧
- **WHEN** 先頭で引っ張って取り直しを始める
- **THEN** インジケータが、指定した色で描かれる

#### Scenario: 差し替えた表示には効かない
- **GIVEN** 色を指定し、次のページの読み込み中と最初の読み込み中を差し替えた一覧
- **WHEN** それぞれの表示が出る状態と件数にする
- **THEN** 差し替えた表示が利用者の書いた色のまま出て、指定した色には変わらない

#### Scenario: 表示中に色を変える
- **GIVEN** ある色を指定し、3 つの表示のどれか (差し替えていない次のページの読み込み中、差し替えていない最初の読み込み中、取り直しの処理が終わるのを待っている Pull to Refresh のインジケータ) を出している一覧
- **WHEN** 表示を出したまま、指定を別の色に変える
- **THEN** 出ている表示が、新しく指定した色で描かれる (3 つの表示のそれぞれで成り立つ)

#### Scenario: 並べ替えのドラッグ中に色を変える (iOS)
- **GIVEN** ある色を指定し、次のページの読み込み中 (差し替えなし) を出している iOS の一覧で、並べ替えのドラッグをしている
- **WHEN** ドラッグの途中で指定を別の色に変える
- **THEN** ドラッグの間は前の色のままで、ドラッグが終わると新しく指定した色で描かれる

#### Scenario: Android の下地は変わらない
- **GIVEN** 色を指定し、取り直しの処理を渡した Android の一覧
- **WHEN** 先頭で引っ張って取り直しを始める
- **THEN** インジケータの矢印が指定した色で描かれ、下地は色を指定しない一覧と同じ色で描かれる

### Requirement: 色を指定しないときの読み込み中の表示
色を指定しない一覧では、3 つの表示 (次のページの読み込み中・最初の読み込み中・Pull to Refresh のインジケータ) は各プラットフォームの標準の色で描かれ、この設定を足す前と見え方が変わらない (SHALL)。指定していた色を外すと、3 つの表示は標準の色に戻り、出ている表示もその場で標準の色に変わる (SHALL)。

**Side Effects**: なし

#### Scenario: 指定しない一覧は標準の色のまま
- **GIVEN** 色を指定せず、表示を差し替えていない、取り直しの処理を渡した一覧
- **WHEN** 次のページの読み込み中・最初の読み込み中・Pull to Refresh のインジケータをそれぞれ出す
- **THEN** 3 つとも、この設定を足す前と同じ色で描かれる (ページングの 2 つは、iOS では親に付けた tint、Android ではテーマの primary に従う。Pull to Refresh は各プラットフォームの標準の色)

#### Scenario: 表示中に指定を外す
- **GIVEN** 色を指定し、3 つの表示のどれか (差し替えていない次のページの読み込み中、差し替えていない最初の読み込み中、取り直しの処理が終わるのを待っている Pull to Refresh のインジケータ) を出している一覧
- **WHEN** 表示を出したまま、色の指定を外す
- **THEN** 出ている表示が、色を指定しない一覧と同じ色で描かれる (3 つの表示のそれぞれで成り立つ)
