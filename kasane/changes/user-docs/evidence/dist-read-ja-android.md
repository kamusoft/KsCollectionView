## 1. 冒頭

分かります。足りないものはありません。

- 何のライブラリか: 「KsCollectionView は、リストとグリッドの画面を作るための UI ライブラリです。自分のモデルのプレーンな `List` と、項目 1 つを描く Composable のラムダを渡すと、スクロールするリストやグリッドとして表示します。」
- どのプラットフォームか: 「この Skill が扱うのは Android 版で、`LazyVerticalGrid` を土台にした `KsCollectionView` という 1 つの Jetpack Compose の Composable です。」
- いつ使うか: frontmatter の description「jp.kamusoft.kscollectionview を import する Kotlin アプリで、リストやグリッドの画面を追加・変更・レビューするときに使う。」
