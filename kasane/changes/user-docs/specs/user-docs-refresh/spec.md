## ADDED Requirements

### Requirement: 追従の記録

追従の記録は、`skills/.manifest.json` の 1 つのファイルに持たなければならない (SHALL)。記録は、前回追従したときに見た commit の ID・差分を出す対象のパスと、それが掛かる Skill の 1 枚・Skill に載せないと決めた公開の宣言の名前を持つ。1 つの源泉は、複数の 1 枚に掛かってよい。

差分を出す対象は、源泉の概念の文書のすべて・対応プラットフォームの値を決めるビルドの設定・依存の書き方を決めている文書・利用者役の画面のファイルである。源泉の概念の文書は、どれも、掛かる Skill の 1 枚か、Skill に掛からない理由のどちらかを持つ。

**Side Effects**: なし

#### Scenario: 記録が決めた項目を持つ
- **GIVEN** 制作が終わった `skills/.manifest.json`
- **WHEN** 中身を読む
- **THEN** 前回追従したときに見た commit の ID・対象のパスと掛かる 1 枚・載せないと決めた名前の 3 つがある

#### Scenario: 概念の文書に、行き先の無いものが無い
- **GIVEN** 今の源泉の概念の文書の一覧
- **WHEN** 記録の対象と突き合わせる
- **THEN** どの文書も、掛かる Skill の 1 枚か、掛からない理由を持つ

#### Scenario: 最初の記録が、制作の見た commit を指す
- **GIVEN** 本変更の制作が終わった時点
- **WHEN** 記録の commit の ID を、リポジトリの履歴で引く
- **THEN** 履歴にある commit で、制作が見た源泉の内容を持つ

### Requirement: 変わった源泉の一覧

追従の道具は、前回追従したときに見た commit から今の作業ツリーまでの、対象のパスの差分を出し、変わった源泉と、見直す Skill の 1 枚を一覧にしなければならない (SHALL)。複数の 1 枚に掛かる源泉は、そのすべてを出す。差分の本文も出せる。この使い方は、何も書き換えない。

記録に対応の無い源泉 (新しい概念の文書) と、名前の変わった源泉は、変わった源泉とは分けて報告する。

本体のソースの、公開の宣言の行の増減 (足された宣言の行と、消えた宣言の行) も、変わった源泉とは分けて報告する。公開の宣言でない行の変更は、報告しない。

**Requires**:
- 記録の commit が、手元の履歴にあること
- 記録のファイルが、決めた形で読めること

**Side Effects**: なし

#### Scenario: 変わっていなければ、変わった源泉は無いと出る
- **GIVEN** 記録の commit の後に、対象のパスが変わっていない
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 変わった源泉が無いことが出て、成功で終わる

#### Scenario: 変わった源泉と、見直す 1 枚が出る
- **GIVEN** 記録の commit の後に、ページングの概念の文書を変えて commit した
- **WHEN** 変わった源泉の一覧を出す
- **THEN** その文書と、掛かる 1 枚 (ページングの 1 枚) が出る

#### Scenario: 複数の 1 枚に掛かる源泉は、そのすべてが出る
- **GIVEN** 記録の中で、2 つの 1 枚に掛かると書かれた概念の文書を変えた
- **WHEN** 変わった源泉の一覧を出す
- **THEN** その文書に、掛かる 2 つの 1 枚の両方が出る

#### Scenario: 公開の宣言を消すと、消えた宣言として出る
- **GIVEN** 記録の commit の後に、本体のソースから公開の宣言を 1 つ消した。概念の文書は変えていない
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 消えた公開の宣言の行が、公開の宣言の増減として出る

#### Scenario: 公開の宣言の引数を変えると、前の行と今の行が出る
- **GIVEN** 記録の commit の後に、1 行で書かれた公開の宣言の引数を変えた
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 前の宣言の行が消えた行として、今の宣言の行が足された行として出る

#### Scenario: 公開の宣言でない変更は、増減に出ない
- **GIVEN** 記録の commit の後に、本体のソースの、公開の宣言でない行だけを変えた
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 公開の宣言の増減が無いことが出る

#### Scenario: commit していない変更も出る
- **GIVEN** 対象の概念の文書を作業ツリーで変え、commit していない
- **WHEN** 変わった源泉の一覧を出す
- **THEN** その文書が、変わった源泉として出る

#### Scenario: 対象の外の変更は出ない
- **GIVEN** 記録の commit の後に、対象でないファイル (Sample のソース) だけを変えた
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 変わった源泉が無いことと、公開の宣言の増減が無いことが出る

#### Scenario: 新しい概念の文書は、対応が決まっていないと出る
- **GIVEN** 記録に無い概念の文書を、新しく足した
- **WHEN** 変わった源泉の一覧を出す
- **THEN** その文書が、対応の決まっていない源泉として出る

#### Scenario: 名前の変わった源泉は、変わったことが分かる
- **GIVEN** 記録にある概念の文書の名前を変えた
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 前の名前と今の名前が出る

#### Scenario: 差分の本文を出せる
- **GIVEN** 変わった源泉がある
- **WHEN** 差分の本文も出す指定で、一覧を出す
- **THEN** 変わった源泉の、どこがどう変わったかが出る

#### Scenario: 記録の commit が履歴に無いと失敗する
- **GIVEN** 記録の commit の ID が、手元の履歴に無い
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 理由を出して失敗で終わり、変わった源泉が無いとは出さない

#### Scenario: 記録が読めないと失敗する
- **GIVEN** 記録のファイルが無い、または決めた項目を欠いている
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 理由を出して失敗で終わる

#### Scenario: 何も書き換えない
- **GIVEN** 一覧を出す前の作業ツリー
- **WHEN** 変わった源泉の一覧を出す
- **THEN** 作業ツリーと履歴のどちらも変わらない

### Requirement: 追従の記録の更新

追従の道具は、記録の commit の ID を、渡した commit (渡さなければ今の先頭の commit) に書き換えなければならない (SHALL)。書き換えるのは、記録のファイルの、この ID だけである。履歴は変えない。

**Requires**:
- 記録する commit が、手元の履歴にあること
- 対象のパスに、commit していない変更が無いこと

**Side Effects**:
- `skills/.manifest.json` の、前回追従したときに見た commit の ID: 更新

#### Scenario: 今の先頭の commit を記録する
- **GIVEN** 対象のパスに commit していない変更が無い
- **WHEN** commit を渡さずに、記録を更新する
- **THEN** 記録の ID が今の先頭の commit になり、その後に変わった源泉の一覧を出すと、変わった源泉が無いと出る

#### Scenario: ほかの項目を変えない
- **GIVEN** 記録を更新する前の、記録のファイル
- **WHEN** 記録を更新する
- **THEN** commit の ID のほかの項目が変わっていない

#### Scenario: commit していない変更があると書き換えない
- **GIVEN** 対象の概念の文書を作業ツリーで変え、commit していない
- **WHEN** 記録を更新する
- **THEN** 理由を出して失敗で終わり、記録のファイルは変わらない

#### Scenario: 履歴に無い commit は記録しない
- **GIVEN** 履歴に無い ID を渡した
- **WHEN** 記録を更新する
- **THEN** 理由を出して失敗で終わり、記録のファイルは変わらない

#### Scenario: 履歴を変えない
- **GIVEN** 記録を更新する前の履歴
- **WHEN** 記録を更新する
- **THEN** commit が増えていない

### Requirement: 公開の宣言の名前の網羅の報告

網羅を報告する道具は、各プラットフォームのソースから公開の宣言の名前 (型・関数と修飾子・プロパティ・列挙の値) を拾い、そのプラットフォームの Skill の英語版と日本語版のそれぞれに、一度も現れない名前を報告しなければならない (SHALL)。引数の名前と初期化の宣言は拾わない。利用者向けでない印の付いた公開の宣言は拾わない。

載せないと決めた名前は報告しない。載せないと決めた名前のうち、宣言が無くなったものは、古い項目として報告する。

道具は、Skill もソースも書き換えない。漏れがあるときは、漏れがあったと分かる終了コードで終わる。

**Requires**:
- 各プラットフォームのソースから、公開の宣言を 1 つ以上拾えること
- そのプラットフォームの Skill が、両方の言語にあること

**Side Effects**: なし

#### Scenario: すべての名前が現れていれば、漏れは無いと出る
- **GIVEN** 公開の宣言の名前が、載せないと決めたものを除いて、すべて Skill に現れている
- **WHEN** 網羅を報告する
- **THEN** 漏れが 0 件と出て、成功で終わる

#### Scenario: 現れない名前が報告される
- **GIVEN** 公開の宣言のうち 1 つの名前が、iOS の Skill のどこにも無い
- **WHEN** 網羅を報告する
- **THEN** プラットフォーム・言語・その名前が出て、漏れがあったと分かる終了コードで終わる

#### Scenario: 片方の言語にだけ無い名前も報告される
- **GIVEN** ある名前が、英語版にはあり、日本語版には無い
- **WHEN** 網羅を報告する
- **THEN** 日本語版の漏れとして出る

#### Scenario: 載せないと決めた名前は報告されない
- **GIVEN** Skill に現れない名前が、載せないと決めた名前の一覧にある
- **WHEN** 網羅を報告する
- **THEN** その名前は漏れとして出ない

#### Scenario: 載せないと決めた名前の宣言が無くなると、古い項目として出る
- **GIVEN** 載せないと決めた名前の一覧にある名前が、ソースの公開の宣言に無い
- **WHEN** 網羅を報告する
- **THEN** その名前が、古い項目として出る

#### Scenario: 利用者向けでない印の付いた宣言は拾わない
- **GIVEN** 利用者向けでない印の付いた公開の宣言が、Skill に現れない
- **WHEN** 網羅を報告する
- **THEN** その名前は漏れとして出ない

#### Scenario: 相手のプラットフォームの名前を、漏れに数えない
- **GIVEN** Android にだけある公開の宣言の名前が、iOS の Skill に無い
- **WHEN** 網羅を報告する
- **THEN** iOS の漏れとして出ない

#### Scenario: 宣言を 1 つも拾えないと失敗する
- **GIVEN** ソースの置き場が変わり、公開の宣言を 1 つも拾えない
- **WHEN** 網羅を報告する
- **THEN** 理由を出して失敗で終わり、漏れが 0 件とは出さない

#### Scenario: Skill が無いと失敗する
- **GIVEN** あるプラットフォームの Skill が、片方の言語に無い
- **WHEN** 網羅を報告する
- **THEN** 理由を出して失敗で終わる

#### Scenario: 何も書き換えない
- **GIVEN** 網羅を報告する前の作業ツリー
- **WHEN** 網羅を報告する
- **THEN** 作業ツリーが変わらない
