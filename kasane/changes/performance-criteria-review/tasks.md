- [x] 7.2 区切り線の先頭判定を「先頭の塊の先頭の項目」に置き換え、塊の境界で上線が出ないことをエンジンテストで確かめる (→ Scenario: 塊の境界で行間と区切り線が変わらない)
- [x] 7.3 列数の候補の最小公倍数と塊の件数の算出 (オーバーフローと 2,000 超の縮退、互いに素な大きい列数を含む) を単体テストで確かめ、向き別列数の切り替えで塊を組み直さずに不完全な行が出ないこと、adaptive の列数変化で塊の件数が割り切れなくなったときだけ組み直して表示範囲の先頭の項目を保つこと (同値配列の早期 return より前に判定する)、割り切れる変化 (2 列 → 4 列) では組み直さないことをエンジンテストで確かめる (→ Scenario: 塊の境界に不完全な行が無い / 向き別列数で列数が変わっても不完全な行が無い / adaptive で列数が変わると塊を組み直して位置を保つ)
