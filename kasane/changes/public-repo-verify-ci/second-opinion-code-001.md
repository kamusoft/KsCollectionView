## 指摘事項

### [🟡 Minor] 版を指定していないランナー名が定義検査を通る

**該当箇所**: `scripts/ci/check-workflows.py:228`

**問題点**: `check_runner_labels()` は式と `latest` を含む名前だけを拒否している。そのため、`runs-on: self-hosted` のように版の指定を持たない名前でも、問題なしとして返る。これはスクリプト冒頭の「版を読み取れない選び方は使わない」という説明より検出範囲が狭い。

現在の 3 本は `ubuntu-24.04`・`xcode-27` を指定しているため、現行 CI への直接の影響はない。ただし、ランナー指定の変更時に、版固定の退行をこの検査で捕捉できない。

**推奨修正**: 現在許容する版付きラベルを明示して照合するなど、版固定を確認できない指定も失敗にする。版指定のないラベルを拒否する異常系テストを追加する。
