# Delta Spec: collection-layout (library-default-colors-dark-mode)

両プラットフォーム共通。既存の「区切り線の色 (両プラットフォーム)」(android-wrapper-foundation で追加) の、色を指定しないときの扱いを変える。線の位置・太さ・本数・描画順と、グループを持つ list の線の位置は変えない。

利用者が指定した色の扱いは変えない。iOS で、利用者が外観で値の変わる色を指定したときにその変わり方がどこまで保たれるかも、この変更では変えない (今の挙動のまま。iOS の版による違いは `evidence/proposal-probes.md` の 4)。

## MODIFIED Requirements

### Requirement: 区切り線の色 (両プラットフォーム)
区切り線の色は、表示の有無 (`listSeparators`) とは独立した語彙 `listSeparatorColor` (Swift: `.listSeparatorColor(_:)` modifier / Kotlin: `listSeparatorColor =` 引数) で指定できる (SHALL)。未指定時はライブラリ既定の色を使う (SHALL)。既定の色はライト用とダーク用の 2 つの値を持ち、描くときの表示モードの側の値で描く (SHALL)。既定の色の値は、ライト・ダークとも両プラットフォームで同じとする (SHALL)。ライト用の値は、この変更の前の既定の色と同じとする (SHALL)。表示モードは、iOS では一覧が置かれた場所の外観 (アプリが上書きした外観を含む) で決める (SHALL)。Android では一覧が置かれた画面の構成の夜間モード (`isSystemInDarkTheme()` が返す値。通常は端末の表示モードに追随し、アプリが画面の構成を上書きしたときはその値) で決め、Material のテーマの配色は判定に使わない (SHALL)。表示中に表示モードが切り替わると、色を指定していない区切り線は切り替わった側の既定の色で描かれる (SHALL)。利用者が指定した色に、ライブラリは手を加えない: 表示モードによって別の色に差し替えず、既定の色に置き換えない (SHALL NOT)。`listSeparators` が非表示のとき `listSeparatorColor` は何も描かせない (SHALL)。

**Side Effects**: なし

#### Scenario: 色の指定
- **GIVEN** `listSeparatorColor` に色を指定したリスト
- **WHEN** 表示する
- **THEN** 区切り線が指定した色で描かれ、位置・本数は既定と同じ

#### Scenario: 非表示との組み合わせ
- **GIVEN** `listSeparators = false` と `listSeparatorColor` の両方を指定したリスト
- **WHEN** 表示する
- **THEN** 区切り線は表示されない

#### Scenario: ライトの既定の色
- **GIVEN** 色を指定していないリスト。表示モードはライト
- **WHEN** 表示する
- **THEN** 区切り線がライト用の既定の色で描かれる。その色は、この変更の前の既定の色と同じ

#### Scenario: ダークの既定の色
- **GIVEN** 色を指定していないリスト。表示モードはダーク
- **WHEN** 表示する
- **THEN** 区切り線がダーク用の既定の色で描かれる。位置・本数はライトのときと同じ

#### Scenario: 表示中に表示モードが切り替わる
- **GIVEN** 色を指定していないリストをライトで表示している
- **WHEN** 画面を作り直さずに表示モードをダークに切り替え、その後ライトに戻す
- **THEN** 表示中の区切り線がダーク用の既定の色になり、戻すとライト用の既定の色に戻る。位置・本数は変わらない

#### Scenario: 固定の色を指定すると表示モードで変わらない
- **GIVEN** `listSeparatorColor` に、外観で値の変わらない色を 1 つ指定したリスト
- **WHEN** ライトで表示する / ダークで表示する
- **THEN** どちらでも区切り線は指定した色で描かれる

#### Scenario: 指定を外すと表示モードの側の既定の色になる
- **GIVEN** `listSeparatorColor` に色を指定したリストをダークで表示している
- **WHEN** 色の指定を外す
- **THEN** 区切り線がダーク用の既定の色で描かれる

#### Scenario: アプリが外観を上書きした場所に置く (iOS)
- **GIVEN** 端末の表示モードはライトで、一覧を置いた画面の外観をアプリがダークに上書きしている
- **WHEN** 色を指定していないリストを表示する
- **THEN** 区切り線がダーク用の既定の色で描かれる

#### Scenario: 画面の構成の夜間モードで決まる (Android)
- **GIVEN** 端末の表示モードがダークで、アプリは画面の構成を上書きしていない。アプリは Material のテーマを置いていない、またはライトの配色の Material のテーマを置いている
- **WHEN** 色を指定していないリストを表示する
- **THEN** 区切り線がダーク用の既定の色で描かれる

#### Scenario: アプリが画面の構成を上書きした場合 (Android)
- **GIVEN** 端末の表示モードはライトで、アプリが一覧を置いた画面の構成の夜間モードをダークに上書きしている
- **WHEN** 色を指定していないリストを表示する
- **THEN** 区切り線がダーク用の既定の色で描かれる

#### Scenario: Material の配色だけをダークにした場合 (Android)
- **GIVEN** 画面の構成の夜間モードはライトのままで、アプリがダークの配色の Material のテーマだけを置いている
- **WHEN** 色を指定していないリストを表示する
- **THEN** 区切り線がライト用の既定の色で描かれる (Material の配色には追随しない)

#### Scenario: 両プラットフォームで同じ値
- **GIVEN** 両プラットフォームのライブラリ
- **WHEN** ライト用とダーク用の既定の色の値を比べる
- **THEN** どちらの値も両プラットフォームで同じで、承認 mock の色の表の値と一致する
