# UI Brief: library-default-colors-dark-mode

## 画面と状態

対象は、ライブラリの既定の色がそのまま見える両プラットフォームの Sample の画面。画面の構造・文言・操作は変えない。変えるのは次の表示の色だけである。

- ① list の区切り線 (色を指定しないとき) — デモ画面「リスト」で区切り線「既定」を選んだ状態。先頭行の上端・行の間・最終行の下端に出る
- ② 画像の読み込み中の既定の表示 — デモ画面「画像グリッド」で、画像が届く前のセル。技術検証画面「検証: 画像の挙動」にも出る
- ③ 画像の失敗の既定の表示 (下地と印) — 技術検証画面「検証: 画像の挙動」の、取得できない画像
- ④ タップしたときの色 — デモ画面「リスト」で行を押している間。ライブラリの挙動は変えず、Sample が両プラットフォームに渡す値をそろえる

① ② ③ は、外観 (ライト / ダーク) のそれぞれで、その外観の側の値になる。値は両プラットフォームで同じにする。④ は、iOS が渡した色をそのまま塗り、Android が色みだけを使って標準の濃さで出すので、同じ値を渡しても濃さは一致しない (core/ADR-0037)。

mock で決めないもの: 行・グリッド・ナビゲーションの形と大きさ、失敗の印の形 (iOS は写真のアイコン、Android は四角と丸で、今のまま)、波紋の動き。mock の絵は近似で、mock と照合するのは色だけにする。mock では比べやすいように失敗の表示を「画像グリッド」の中に並べたが、実物で失敗の既定の表示が出るのは「検証: 画像の挙動」である。

## リファレンス注釈

`ui/references/` に画像なし。

見た目の出発点は、今の iOS の画像の既定の表示 (OS の灰色)。ライトとダークの値をそこから採り、iOS の見え方を変えずに Android をそろえる。区切り線のライトは今の値のままにする。

提案の段階の実測 (`evidence/proposal-probes.md`) で分かったこと: 画像に使う 3 つの灰色は iOS 17.5〜27.0 で同じ値だった。区切り線の不透明な色は iOS 27 で OS の値が変わっており、mock に参考として並べた。Android の波紋の押している間の濃さは約 8% (Android 16 のエミュレータ) で、mock の ④ の絵はこの値で描いた。

## デザイントークン参照

concepts/ に UI トークンは未登録。この変更で決める色は Sample の配色 (`SampleTheme`) ではなく、ライブラリ自身が持つ既定の色である。値の正は承認 mock の「色の表」とし、実装とテストはその表の値を使う。

- 区切り線・画像の読み込み中・画像の失敗の下地・画像の失敗の印: ライブラリの既定の色 (ライト / ダークの 2 組)。Sample のトークンには足さない
- タップしたときの色: Sample の既存のトークン「アクセント」に不透明度を掛けた値を、両プラットフォームで同じ式で渡す。新しいトークンは足さない
- 下地・行・文字・アクセント: Sample の既存のトークンのまま

視認性の考え方: 区切り線と画像の既定の表示は、目立たせる部品ではなく控えめな下地である。ライトの今の見え方 (区切り線は白の上でコントラスト比 約 1.4) と同じ程度の控えめさを、ダークでも保つ。

## 承認モック

案 A を採用 (`mock/default-colors-a-ios-standard.html`、ページ全体を撮った `mock/approved.png`。2026-10-06 オーナー承認)。ライブラリの既定の色の値は、この mock の「色の表」を正とする。

タップしたときの色に Sample「リスト」が渡す値は、アクセントの 10% とする (2026-10-06 オーナー決定)。iOS は渡した 10% のまま、Android は標準の波紋の濃さ (実測で約 8%) で出て、両プラットフォームの見え方がいちばん近くなる。変更前の iOS の値 (15%) は採らない。

案 B (`mock/default-colors-b-one-step-brighter.html` — ダークの区切り線と画像の下地を 1 段明るい灰色にする案) は採らない。区切り線がライトよりくっきり出て控えめさがそろわず (暗い行の上のコントラスト比が 1.7〜1.9。ライトは 1.4)、iOS の画像の既定の表示が今より明るくなり、KsSettingsView の区切り線とも違う値になるためである。

mock の「参考: 区切り線のダークの候補を並べる」の段にある iOS 27 の OS の値も採らない。Sample の暗い行の上でコントラスト比が 1.1 しかなく、線として見分けにくい。

approved.png に個人情報が写っていないことを確認した (架空の時刻、果物の名前と「Item N」の行だけ)。
