案 B: 操作を下部バーに固定

グリッドを上に広く取り、画面下部のバーに操作をまとめる。バーは 2 行: プリフェッチの 3 択 (全幅) と、説明文言 + 「キャッシュを消去」。親指で届く位置に操作が集まり、グリッドの可視件数が 1 行分増える (実機計測の観察面が広い)。
