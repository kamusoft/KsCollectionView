# 独立コードレビュー: sections-grouping

**判定: CHANGES_REQUESTED**（Major 1 件）

### 🟠 Major — iOS でグループの指定を変えても、同じ配列なら再グループ化されない

**該当箇所:** `ios/Sources/KsCollectionView/KsCollectionViewController.swift:159`、同 `:670`

**問題点:** `.groups(by:)` のキーパスを切り替えても、変更判定は宣言の有無しか見ません。項目配列が同値なら `apply` が早期終了し、塊とグループ境界が更新されません。一方、可視見出しには新しいクロージャが適用されるため、**古い境界に新しいグループ名を表示する**状態にもなります。たとえば同じ配列をカテゴリ別から地域別へ切り替える場合に起きます。Swift の公開 API と仕様には、この指定を表示中に固定する契約がありません。

**推奨修正:** 更新時に新しい指定からグループ値の列を求め、適用済みの列と比較して、変われば同値配列でも snapshot を組み直してください。キーパスだけを切り替える回帰テストも追加してください。

照合した規約は、ソースコメント規約、Sample のプラットフォーム間一致、iOS・Android の性能検証手順です。合意済み deviation と UI の妥協は指摘対象から除外しました。**静的レビューのみ**を行い、ビルド・テストは実行していません。ご提示の成功結果を前提としています。ファイルへの書き込みは行っていません。
