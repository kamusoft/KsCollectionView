# 5.7 端を表示中の端への挿入 (オーナー目視)

- 日付: 2026-09-26
- 端末: iPhone 11 (iOS 18.7.8、Release ビルド) / Pixel 4a (Android 13、benchmark ビルド)
- 画面: Sample「差分更新」、list とグリッドのそれぞれ
- 手順: いちばん上を表示中に「先頭」→「挿入」、いちばん下を表示中に「末尾」→「挿入」。あわせて「中ほど」の挿入 / 削除 / 更新 / 移動、「反転」「シャッフル」、「グループ」スイッチのオン / オフ
- 結果: オーナー判定「OK」— 両プラットフォーム・list / グリッドとも、先頭 / 末尾への挿入のアニメーションが見え、端に留まる。その他の操作にも問題の指摘なし
- 関連: 5.2 の所見 (「グループ化」の途中での反転で一瞬空になり最後に跳ぶ) は同じ機会に iPhone 11 で目視し「気になるが妥協できる」— deviation.md に合意済みの妥協として記録
