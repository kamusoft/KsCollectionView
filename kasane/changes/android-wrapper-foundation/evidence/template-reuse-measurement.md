# Android テンプレート呼び出しによる再利用の確認

## 状態

実施済み。Layout Inspector は GUI 操作を要するため使わず、**Sample の debug 構成に置いた
テンプレートカウンタの数値**で代替した (乖離として `deviation.md` に記録済み)。カウンタは
2 つの値を数える。

| 数える対象 | 何が分かるか |
|---|---|
| 累計の呼び出し回数 | 一度作られた項目が範囲外へ出るまで作り直されないこと |
| 同時生存数 (現在値・最大値・破棄回数) | 同時に載っているテンプレートが可視範囲 + 先読み分に留まり、範囲外へ出た分が実際に破棄されること |

同時生存数は項目ごとの `DisposableEffect` で増減させる。累計だけでは「同時に何個載っているか」
「範囲外へ出た分が捨てられたか」に答えられないため、Layout Inspector で目視するのと同じ問いに
答えられるようにこの 2 つ目を持つ。

| 対象 | 環境 |
|---|---|
| Sample「大量件数」画面 | Pixel 4a / Android 13 (SDK 33) / debug 構成 |

カウンタは debug 構成にだけ実体があり、配布する構成 (release) では何もしない実装に差し替わる。
差し替えが効いていることは、release の APK に計数の実装が入っていないことで確認した (下記)。

## 固定 fixture

- 画面: Sample「大量件数」
- 件数: 10,000 件
- 配置: 2 列グリッド、行間 / 列間 1dp
- 行高: 固定高と、7 件ごとの長文による可変行高の混在
- 生成: 整数 ID 1〜10,000 による決定的なデータ

## 手順

1. Sample を debug 構成で実機へインストールし、アプリを完全に停止してからログを消す。
2. 起動時の経路指定で「大量件数」を直接開き、表示が落ち着くまで待つ。
3. カウンタの値を読む (= 初期表示だけで評価されたテンプレートの数と、そのときの同時生存数)。
4. 実座標のフリックを 20 回続けてから、カウンタの値と画面に見えている項目番号を読む。

## 結果

| 時点 | 画面に見えている項目 | 累計の呼び出し | 同時生存 (現在) | 同時生存 (最大) | 破棄 |
|---|---:|---:|---:|---:|---:|
| 初期表示 (スクロールなし) | Item 1〜22 | 22 | 22 | 22 | 0 |
| 実座標フリック 20 回の後 | Item 379〜400 | 402 | 24 | 32 | 378 |

- **初期表示は 22 回**。10,000 件を渡しても評価されたのは可視範囲の 22 項目だけで、件数に
  比例しない。仮想化が効かなければここが 10,000 になる。
- **同時生存の最大は 32**。フリックで 400 項目を通過しても、同時に載っているテンプレートは
  可視範囲 (22) に先読み分を足した数に留まる。件数にも通過数にも比例しない。
- **破棄 378 / 累計 402**。通過して範囲外へ出た項目は実際に捨てられている (累計 - 破棄 = 24 が
  そのときの現在値と一致する)。累計 402 は「通過した項目 (約 400) + 可視範囲 (22)」でほぼ説明でき、
  同じ項目が繰り返し評価されてはいない。

ログの抜粋 (`scripts/log-sanitize.py` を通したもの):

```
I KsTemplateCounter: LargeData=22
I KsTemplateCounter: LargeData alive=22 max=22
...
I KsTemplateCounter: LargeData alive=26 max=32
I KsTemplateCounter: LargeData alive=24 disposed=378
```

## 配布する構成に計数が入らないこと

`app` の release 構成では、計数と計測用画面がソースセットごと空実装へ差し替わる。ビルド後の APK に
含まれる識別子を数えて確認した。

| 構成 | 計数の実装 | 比較対象画面 | 自動往復の画面 |
|---|---|---|---|
| debug | あり | あり | あり |
| release | 空実装のみ (ログの印は 0 件) | なし | なし |

## 判定

再利用は成立している。10,000 件でも同時に載るテンプレートは可視範囲 + 先読み分 (最大 32) に留まり、
範囲外へ出た項目は破棄される。累計の呼び出しも通過した項目の数以上には増えない。
