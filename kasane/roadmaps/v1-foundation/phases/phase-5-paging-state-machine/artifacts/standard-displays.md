# 標準の表示部品のイメージ (2026-09-27 の議論で使った図)

議論の途中で使った 6 つの表示の図 (点線の枠)。最終的な決定 (2026-09-27) では、既定で出すのは 2 つの「読み込み中」だけ (標準のくるくる、文言なし) で、失敗・終端・空の 4 つは既定では何も出さず、利用者が設定したときだけ出る。6 つとも差し替え口で設定できる。

## 項目が並んでいるとき — いちばん下の項目のすぐ下に小さく出る

| 場面 | 表示 |
|---|---|
| 次のページを読み込み中 | くるくる + 「読み込み中」 |
| 次のページの読み込みに失敗 | 「読み込めませんでした」 + 「再試行」ボタン |
| 最後まで読み終えた | 「これ以上ありません」 |

```
┌────────────┐
│ ▭ 項目      │
│ ▭ 項目      │
│ ▭ 項目      │
│┌╌╌╌╌╌╌╌╌╌╌┐│
│╎ ◌ 読み込み中 ╎│  ← いちばん下の項目のすぐ下
│└╌╌╌╌╌╌╌╌╌╌┘│
└────────────┘
```

## 項目が 1 件もないとき — 一覧の真ん中に大きく出る

| 場面 | 表示 |
|---|---|
| 最初の読み込み中 | くるくる + 「読み込み中」 |
| 最初の読み込みに失敗 | 警告のアイコン + 「読み込めませんでした」 + 「再試行」ボタン |
| 読み込んだら中身が 0 件 | 箱のアイコン + 「項目がありません」 |

```
┌────────────┐
│            │
│┌╌╌╌╌╌╌╌╌╌╌┐│
│╎     ◌      ╎│  ← 一覧の真ん中
│╎  読み込み中  ╎│
│└╌╌╌╌╌╌╌╌╌╌┘│
│            │
└────────────┘
```
