# handbook 一覧 (ドメイン地図)

規約・ガイド (規範層) はドメイン別に管理する。ドメイン導出規則は [concepts/rules.md](../concepts/rules.md) を参照。

| ドメイン | 説明 |
|---|---|
| core | 全 platform が共有する規約・ガイド |
| ios | iOS 固有の規約・ガイド |
| android | Android 固有の規約・ガイド |
| [cross](cross/index.md) | リポジトリ横断の規約・ガイド (リポジトリ構成・命名・ハーネス運用) |

規約・ガイドを持つドメインは名前がその index へのリンクになっている。ドメインディレクトリと各ドメインの index は最初の文書が生まれるときに作成する。

各ドメインの index は「文書 / 適用のきっかけ / 種別 (rule | guide)」の表にし、適用のきっかけ (触る対象・行う作業) から引ける形で書く。
