## Context

ページングの公開契約は、利用者 (VM) が 5 状態 (idle / refreshing / appending / failed / endReached) を持ち、DSL に状態と次ページ要求のコールバックを渡す形に決まっている (core/ADR-0005)。ADR-0005 は「failed にエラー内容を持たせるか」を未決として残した。

ライブラリが見分けて出し方を変える場面は、初回の読み込み中・初回の読み込みの失敗・空・追加読み込みの失敗・項目があるときの取り直し (Pull to Refresh) の失敗である。ライブラリが知る必要があるのは、エラーをどこに出すか (項目が 1 件もない一覧の真ん中か、いちばん下の項目のすぐ下か) と、再試行で何を呼ぶかの 2 つである。初回の読み込みは次ページ要求で始まり (core/ADR-0020)、VM の次ページ要求の処理は項目が空なら最初のページを読むため、項目が 1 件もない一覧の再試行は、次ページ要求でも取り直しでも最初のページを読み直すことになる。Pull to Refresh を付けていない一覧には取り直しの処理が無い。

前提: テンプレートは利用者のクロージャなので、エラーの文言などの状態以外の値は VM から直接読める。KMP の共有 VM は自分の状態を持ち、各プラットフォームでライブラリの状態へ写す。

## Decision

- 失敗の状態は中身 (エラーの値・どの読み込みの失敗か) を持たない。5 状態は付属値のない列挙のままにする (Swift は付属値のない enum、Kotlin は enum class)
- エラーをどこに出すかは、ライブラリが項目が空かどうかで決める。失敗で項目が 1 件もなければ一覧の真ん中に出し、項目があればいちばん下の項目のすぐ下に出す
- 再試行は、項目が空かどうかにも Pull to Refresh を付けたかどうかにもよらず、いつも次ページ要求のコールバックを呼ぶ
- 項目があるときの取り直しの失敗は、失敗の状態にせず元の状態に戻し、知らせるのはアプリ側で行う、と利用者向けガイドに書く
- エラーの文言を見せたいときは、差し替えたテンプレートが VM から読む

## Alternatives Considered

- **失敗に「取り直し / 次のページ」のどちらの失敗かを持たせる**: 却下。再試行の行き先は明示されるが、項目があるときの取り直しの失敗は末尾に「更新に失敗」を出すしかなく不自然さが残るため、失敗の状態にしないガイドはどのみち要る。VM が失敗時に書く分岐が 1 つ増え、Kotlin は enum ではなくなる。
- **項目が空なら取り直しの処理を呼び、Pull to Refresh を付けていなければ次ページ要求を呼ぶ**: 却下。失敗した処理と同じ処理でやり直せる場面は増えるが、規則が 2 段になって Pull to Refresh を付けたかどうかで振る舞いが変わり、VM は取り直しの処理でも失敗の状態からの呼び出しを受け付ける必要がある。読み込まれる中身はどちらも最初のページで同じ。
- **失敗にエラーの値を持たせる**: 却下。差し替えたフッターが VM を読まずにエラーを出せるだけで、Swift ではエラーの型が比較できないため状態どうしの比較が自動では成り立たなくなり、Kotlin は enum ではなくなり、KMP の共有 VM のエラーを各プラットフォームのエラーの型へ橋渡しする手間が出る。エラーの文言はテンプレートが VM から読める。

## Consequences

- 正: 状態は付属値のない列挙のままで、状態どうしの比較がそのまま書け、KMP の共有 VM の状態と 1 対 1 で写せる。
- 正: VM が失敗時に書くのは「失敗」だけで、ADR-0005 の決定 (5 状態の外形) を変えない。
- 負: 標準の表示部品はエラーの中身を出せない。文言を見せるには、差し替えたテンプレートで VM を読む。
- 正: 再試行の規則が 1 つで、Pull to Refresh を付けたかどうかで振る舞いが変わらない。
- 負: 項目があるときの取り直しの失敗を失敗の状態にしない規律は型で強制できず、ガイド頼みになる。VM が失敗の状態にすると、いちばん下の項目のすぐ下に再試行が出て、押すと次のページを頼む。
- 負: VM の次ページ要求の処理は、失敗の状態からの呼び出しと、項目が空のときの呼び出し (最初のページ) を受け付ける必要がある。0 件の一覧での Pull to Refresh の失敗も、取り直しではなく次ページ要求でやり直す。
- 負: 後から失敗に中身を足すと、状態を分岐する利用者のコード (Swift の switch・Kotlin の when) を壊す変更になる。
