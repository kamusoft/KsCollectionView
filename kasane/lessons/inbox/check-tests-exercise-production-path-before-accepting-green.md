## ルール文
Scenario に対応するテストが存在し緑であることを、その契約が満たされている根拠にしない。レビュアーは契約の中核をなす Scenario について、**テストが本番と同じ経路で対象を組み立てているか** (要求の生成経路・キャッシュ鍵・初期状態・観測している状態遷移) をテストコードで確かめ、テストが簡略化した経路を通しているときは、その簡略化によって契約の検査が無効になっていないかを判定に書く。テストの存在と件数だけを対応表に記入して充足と見なさない。
