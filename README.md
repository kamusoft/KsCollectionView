# KsCollectionView

[日本語](README_ja.md)

KsCollectionView is a list and grid library for SwiftUI on iOS and Jetpack Compose on Android. It offers the common building blocks of list screens, such as paging, pull to refresh, grouping, and drag-and-drop reordering, through matching APIs on both platforms.

## Status

This library is under preparation. No package has been published yet, so it cannot be installed through Swift Package Manager or Maven at this time. Installation and usage guides will be added here when the first version is released.
