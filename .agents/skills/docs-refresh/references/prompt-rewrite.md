# ひな形: 書き直し (利用者向け Skill 1 つの英語版と日本語版の組)

メインが、利用者向け Skill 1 つごとに、器 `ksn-scribe` を指定して起動したワーカーに渡す (Claude Code: Agent ツールの `subagent_type` に `ksn-scribe` を指定する / codex: エージェントの名前 `ksn-scribe` を指定して spawn する)。器を指定しない起動はしない。

`{{…}}` を埋めてから渡す。当てはまるものが無い節は「なし」と書く (節ごと消さない)。先頭のコンテキストパッケージの節は削らない。メインは、源泉の本文と差分の本文をここに貼らない (パスとコマンドだけを書く)。
