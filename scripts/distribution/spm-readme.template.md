# KsCollectionView — Swift Package Manager distribution

This repository is a **distribution mirror**. It holds a copy of the iOS Swift package of
KsCollectionView so that Swift Package Manager can resolve it from a repository root, and
nothing else.

The source code, documentation, and issue tracker all live in the main repository:

**https://github.com/kamusoft/KsCollectionView**

## Installation and usage

Installation instructions, supported versions, and usage guides are published in the main
repository. See its [README](https://github.com/kamusoft/KsCollectionView#readme).

## Issues and contributions

Do not open issues or pull requests here. This repository is generated from the main
repository, and any change made directly to it is overwritten by the next release.

Report problems and send proposals to
**https://github.com/kamusoft/KsCollectionView/issues**.
